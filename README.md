# 🪲 ISOPOD GROVE (콩벌레 숲)

콩벌레(등각류)를 키우고 모으고 싸우게 하는 **브라우저 방치형 육성 게임**이에요.
사육장을 가꿔 식구를 늘리고, 숲을 탐색해 새로운 종을 만나고, 전투·장비·보스 타워로 성장하고, 친구와 채팅하고 우편으로 보상을 받아요.

- 서비스 주소: <https://isopogrove.click>
- 로그인: Google 계정
- 업데이트 내역: [CHANGELOG.md](frontend/src/data/CHANGELOG.md) (날짜별·카테고리별, 게임 안 사이드바 '업데이트 내역'에서도 볼 수 있어요)

## 주요 기능

### 사육과 수집
- **사육장 관리**: 사육장마다 먹이·습도·온도를 돌봐요. 환경이 쾌적하면 식구가 번식하고 자동 수익이 나와요(자리를 비워도 최대 8시간까지 진행돼요. 단, **전설·신화 번식은 자리를 비운 시간 전부**가 반영돼요 — 서버가 잰 실제 경과 시간만 인정하고, 자동 먹이 공급기·자동 분무기로 환경이 유지될 때 진행돼요).
- **등각류 도감**: 60종(일반 11 · 희귀 7 · 에픽 18 · 전설 15 · 신화 9)을 모아요. 새 종을 만나면 다이아를 받아요.
- **숲 탐색**: 탐색할 때마다 같은 종 2마리를 만나요. 등급 확률이 낮고 비용이 계속 올라가요.
- **원정**: 숲 탐색 비용의 수십~수백 배를 내고 에픽 이상을 확정으로 만나요(대원정은 전설·신화 확률이 더 높아요). 신화는 천장이 있어요.
- **분양 마켓**: 시세가 5분마다 ±25% 범위에서 오르내려요. 실수로 팔지 않도록 종을 잠글 수 있어요.
- **오늘의 숲 날씨**: 실제 서울 날씨(맑음·흐림·비·뇌우·눈·폭염·한파)가 게임 속 숲 날씨가 돼요. 날씨가 편드는 계열 종은 번식이 빨라지고, 숲 탐색·원정에서도 더 잘 만나요. 모든 유저에게 같은 날씨가 적용돼요.
- **사육장 이름**: 사육장마다 이름을 무료로 바꿀 수 있어요(최대 20자). 다른 유저가 사육장을 구경할 때도 이 이름이 보여요.
- **사육장 꾸미기**: 골드로 배경·소품 장식 25종을 사서 사육장마다 배경 1개와 소품 4칸을 꾸며요. 계열(불꽃·숲·서리) 장식은 그 사육장에 사는 같은 계열 종의 번식을 빠르게 해요.
- **업그레이드**: 사육장 확장, 바닥재(수익), 번식 쉼터(번식 시간), 자동 먹이 공급기, 자동 분무기.
- **부스트 상점**: 골드를 내고 일정 시간 동안 수익·번식·전투 경험치를 2배로 만들어요.
- **종 별명**: 내 화면에서만 보이는 별명을 지어줄 수 있어요.

### 전투와 성장
- **야생 배틀**: 상대 희귀도를 직접 골라 턴제로 싸워요. 종마다 전투 레벨이 따로 올라요. 자동 전투 외에 매 턴 행동을 고르는 **직접 전투**도 있어요(보스 타워·서바이벌 엘리트도 마찬가지).
- **전투 훈련**: 강도 3단계(가벼움·보통·강도 높음)와 극한 훈련(다이아 소모, 경험치 ×12).
- **투기장(PvP)**: 다른 유저가 정해 둔 방어 식구와 비동기로 싸우고 레이팅을 올려요. 이긴 상대에게는 30분 동안 재도전할 수 없어요.
- **보스 타워**: 50층, 5층마다 패턴 보스가 있어요. 난이도 4단계(쉬움·보통·어려움·매우 어려움)가 있고 깬 층은 난이도별로 따로 기록돼요. 자동 전투 외에 매 턴 행동을 고르는 **직접 전투**도 있어요.
- **서바이벌(무한 전투)**: 식구 한 마리로 HP를 이어 가며 스테이지를 끝없이 깨요. 5스테이지마다 엘리트가 나오고, 엘리트를 쓰러뜨릴 때마다 버프를 3개 중 하나 골라요.
- **썩은 통나무 던전(로그라이크)**: 식구 한 마리로 난이도마다 **100층**을 올라가요. 층마다 방 2~3개 중 하나를 골라 들어가고(⚔️ 전투 · 💀 엘리트 · 🏕️ 휴식 · 🛒 상점 · ❓ 이벤트 · 💎 보물), 이기면 유물을 하나 골라 빌드를 키워요. 10층마다 한 장이 끝나고(5층 엘리트, 10층 장 보스), 쓰러지면 깬 층만큼 보상을 받아요. 난이도 5단계, 하루 3번.
- **오늘의 퍼즐 "굴러라 콩벌레"**: 하루 10단계, 단계마다 새로운 10×10 슬라이드 퍼즐이 나오고 갈수록 어려워져요(모두에게 같은 순서). 방향을 고르면 바위나 벽에 부딪힐 때까지 굴러가고 🍃에 닿으면 도착이에요. 많이 깰수록·적은 수로 깰수록 높은 순위이고, 별점·단계 보너스·순위 보상이 있어요. 실시간이 아니라 언제든 천천히 풀 수 있어요.
- **콩 달리기 "달려라 콩벌레"**: 가지고 있는 콩벌레 한 마리를 골라(그 종의 그림으로 달려요) 달리면서 곰팡이🦠를 점프로 피하는 러너 게임이에요. 희귀할수록 능력(껍질·점프력·더블 점프)이 많아요. 스페이스·↑·화면 탭·점프 버튼으로 점프하고, 갈수록 빨라지고 곰팡이가 넓어져요. 오늘 가장 멀리 달린 순위와 거리 보너스가 있어요. 점수는 서버가 점프 기록을 다시 돌려서 정해요.
- **장비**: 다이아 뽑기(천장 있음), 레벨업(중복 획득 개수 필요), 각성, 슬롯 확장, 중복 분해·조각 레벨업, 세트 효과. 야생 배틀·투기장·보스 타워·서바이벌에 모두 적용돼요.
- **업적 97종**(사육장 꾸미기·좋아요 업적 포함)과 **일일 퀘스트 4종**, **랭킹**(숲 레벨 · 분당 수익 · 투기장 레이팅 · 보스 타워 · 서바이벌, 그리고 퍼즐·콩 달리기 화면의 오늘의 순위). 모든 랭킹에서 **보기: 20명 / 50명 / 100명**을 고를 수 있고(마지막으로 고른 값을 기억해요), 내 순위가 보여주는 인원 밖이어도 따로 보여줘요.

### 소셜
- **사육장 방문**: 다른 숲지기의 사육장(장식·식구)을 구경하고 사육장마다 ❤️ 좋아요를 눌러요(선물은 없어요). 인기 사육장 순위와 랜덤 방문이 있고, 내 사육장은 설정으로 비공개로 바꿀 수 있어요.
- **친구**: 요청·수락·삭제, 하루 한 번 서로에게 다이아 선물(시스템이 지급하고 선물한 사람은 잃는 게 없어요), 접속 중 표시.
- **친구 채팅**: 친구끼리 1:1 채팅, 읽음 표시, 내 메시지 삭제, 메시지 신고.
- **공동 채팅방**: 자유방·질문방·문의방 3개 채널과 현재 접속자 목록.
- **프로필**: 닉네임(다이아로 변경)과 프로필 메시지, 다른 유저 프로필 보기.

### 우편함과 알림
- **우편함**: 운영자가 보낸 메시지와 자원(골드·다이아·탐색권)을 받아요.
- **웹 푸시 알림**: 친구 메시지·우편이 오거나 누군가 내 사육장에 ❤️ 좋아요를 누르면 브라우저로 알려줘요(알림을 누르면 내 사육장 방문 화면이 열려요). 알림 종류별 켜기·끄기를 지원해요.

### 관리자 (서버 관리 페이지)
- 서버·경제 현황, **우편 발송**(전체/선택 유저, 프리셋, 발송 내역), **채팅 신고 처리**와 **채팅 정지**(N일, 해제).
- 관리자 지정은 `users` 컬렉션에서 해당 유저의 `isAdmin`을 `true`로 바꿔요(화면에서 바꾸는 기능은 없어요).

## 시작하기 (로컬 개발)

### 준비물
- Node.js 22 이상 (운영 서버와 Docker 이미지는 24)
- MongoDB 접속 주소 (로컬 MongoDB 또는 Atlas)
- Google OAuth 클라이언트 (Google Cloud Console → 사용자 인증 정보)
  - 승인된 리디렉션 URI: `http://localhost:3000/api/auth/google/callback`

### 백엔드

```bash
cd backend
cp .env.example .env      # 값을 채운다(아래 환경 변수 표 참고)
npm install
npm run start:dev         # http://localhost:3000/api  (파일을 바꾸면 자동으로 다시 시작)
```

서버가 시작될 때 종·업그레이드·퀘스트·업적 데이터가 DB에 자동으로 반영돼요(시딩).

### 프론트엔드

```bash
cd frontend
cp .env.example .env      # VITE_API_URL=http://localhost:3000/api
npm install
npm run dev               # http://localhost:5173
```

로그인하면 백엔드가 `FRONTEND_URL/auth/callback?token=...`으로 돌려보내고, 프론트가 토큰을 저장해요(JWT 유효기간 7일).

### 자주 쓰는 명령

| 위치 | 명령 | 설명 |
|---|---|---|
| backend | `npm run build` | 컴파일(`dist/`) |
| backend | `npm run start:prod` | 컴파일 결과로 실행 |
| backend | `npm run lint` / `npm test` | 린트 / 테스트(지금은 기본 예제 테스트만 있어요) |
| frontend | `npm run build` | 타입 검사 + 프로덕션 빌드(`dist/`) |
| frontend | `npm run lint` | 린트 |

## 환경 변수

### 백엔드 (`backend/.env`, `backend/.env.example` 참고)

| 변수 | 설명 |
|---|---|
| `PORT` | 서버 포트(기본 3000) |
| `MONGODB_URI` | MongoDB 접속 주소 |
| `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` | Google OAuth 클라이언트 |
| `GOOGLE_CALLBACK_URL` | 로그인 콜백 주소. 예: `http://localhost:3000/api/auth/google/callback` |
| `FRONTEND_URL` | 로그인 후 돌아갈 프론트엔드 주소. 예: `http://localhost:5173` |
| `JWT_SECRET` | JWT 서명 키(`openssl rand -hex 32` 등으로 생성) |
| `VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` / `VAPID_SUBJECT` | 웹 푸시용 키. 비워 두면 푸시만 꺼져요. 생성: `npx web-push generate-vapid-keys` |

> `.env`는 git에 올라가지 않아요. 비공개 키와 비밀번호를 저장소에 커밋하지 마세요.

### 프론트엔드 (`frontend/.env`)

| 변수 | 설명 |
|---|---|
| `VITE_API_URL` | 백엔드 API 주소. 빌드할 때 코드에 박혀요. 예: `http://localhost:3000/api` 또는 같은 도메인이면 `/api` |

## Docker로 실행

백엔드·프론트엔드 각각 `Dockerfile`이 있고, `docker-compose.yml`로 함께 실행해요.

```bash
cp backend/.env.example backend/.env    # 값을 채운다. MongoDB는 외부(Atlas 등)를 가리켜요
docker compose up -d --build
# 접속: http://localhost:8080   (포트 변경: WEB_PORT=80 docker compose up -d)
```

- 프론트 컨테이너(nginx, 8080 포트)가 정적 파일을 서비스하고 `/api`를 백엔드 컨테이너로 프록시해요. 같은 도메인이라 CORS 설정이 필요 없어요.
- compose로 띄울 때는 `backend/.env`의 `FRONTEND_URL`을 `http://localhost:8080`으로, `GOOGLE_CALLBACK_URL`을 `http://localhost:8080/api/auth/google/callback`으로 바꾸고 Google 콘솔에도 같은 콜백 주소를 등록해야 로그인돼요.
- `VITE_API_URL`은 빌드 인자예요(기본 `/api`). 백엔드를 다른 주소로 따로 서비스하면 `--build-arg VITE_API_URL=...`로 넣어요.
- `.env`는 이미지에 들어가지 않고 실행할 때 주입돼요.

## 운영 배포

현재 운영 구성(참고용): 한 서버에서 **nginx**가 `frontend/dist`를 정적 서비스하고 `/api/`를 NestJS(**pm2**, 포트 3000)로 프록시해요.

```bash
# 백엔드
cd backend && npm ci && npm run build
pm2 restart backend            # 처음이면: pm2 start dist/main.js --name backend

# 프론트엔드
cd frontend && npm ci && npm run build   # VITE_API_URL=https://<도메인>/api
```

- **HTTPS가 필요해요**: Google 로그인 콜백과 웹 푸시(서비스 워커)는 HTTPS에서 동작해요.
- nginx는 `sw.js`와 `index.html`을 캐시하지 않게 해야 새 배포와 푸시 알림이 바로 반영돼요(Docker용 `frontend/nginx/default.conf.template` 참고).
- **단일 서버 프로세스를 전제로 해요**: 접속 정보, 채팅 도배 방지, 보스·투기장·서바이벌 동시 요청 잠금이 메모리에 있어요. 서버를 여러 대로 늘리려면 이 상태를 Redis 같은 공유 저장소로 옮겨야 해요.
- 일일 초기화(일일 퀘스트, 무료 탐색권 충전 등)는 **서버의 로컬 시간** 기준이에요.

### 사육
- 환경이 **쾌적**(먹이 25 이상, 습도 65~85%, 온도 20~26°C)하면 수익 100%, 아니면 40%예요. 번식은 먹이 15 이상·습도 50~92%·온도 18~28°C에서만 돼요.
- 돌봄: 먹이 +30, 분무(습도 78%), 온도 조절(24°C). 같은 동작은 10초마다 한 번.
- 사육장은 최대 10개, 이름은 20자 이하로 무료 변경(같은 이름·빈 이름·제어 문자는 거절), 다음 사육장 비용은 `8,750 × 2.5^(보유 수 − 1)` G. 수용량은 기본 20마리에 확장 단계마다 +20.
- 분양은 사육장에 있는 만큼 얼마든지 할 수 있어요(번식은 한 사육장에 같은 종이 2마리 이상 있어야 해요). 이 분양으로 **계정 전체에서 그 종이 0마리가 되면** 확인이 필요해요(전설·신화는 종 이름을 직접 입력). 서버도 확인 값이 없으면 거절해요.
- **종 잠금**: 마켓 카드의 🔓/🔒로 종을 잠그면 어느 사육장에서도 분양할 수 없어요(이사·번식·전투는 그대로). 도감에 있는 종만 잠글 수 있어요.
- 업그레이드: 공간 확장(5단계) · 바닥재(수익 +25%/단계, 5단계) · 번식 쉼터(번식 시간 −12%/단계, 5단계) · 자동 먹이 공급기 · 자동 분무기.

### 오늘의 숲 날씨
- 서버가 30분마다 실제 서울 날씨를 읽어서(Open-Meteo, 키 필요 없음) 숲 날씨로 바꿔요. 날씨를 못 읽으면 직전 기록을 쓰다가, 3시간이 넘으면 "날씨 정보 없음"이 되고 효과도 없어요. 효과는 **전부 이득 쪽**이라서 자리를 오래 비워도 손해가 없어요.
- 날씨 분류(우선순위 뇌우 > 눈 > 비 > 폭염 30°C↑ > 한파 −3°C↓ > 흐림 > 맑음)와 편드는 계열:

| 날씨 | 편드는 계열 |
|---|---|
| ☀️ 맑음 · ⛈️ 뇌우 · 🔥 폭염 | 불꽃 |
| ☁️ 흐림 · ❄️ 눈 · 🥶 한파 | 서리 |
| 🌧️ 비 | 숲 (추가로 사육장 습도가 줄어드는 속도가 절반) |

- **번식**: 편드는 계열 종의 번식 진행이 **+10%**예요. 꾸미기 장식·번식 촉진 부스트와 곱해져요. 시간 진행은 **그 시각의 날씨**를 기록(3일 보관)에서 찾아 적용하고, 8시간을 넘는 자리 비움(전설·신화 번식)에는 적용하지 않아요.
- **탐색·원정**: 뽑힌 등급 안에서 편드는 계열 종이 나올 가능성이 **2배**예요(다른 종이 못 나오게 되지는 않아요. 원정의 "도감에 없는 종 먼저" 규칙은 그대로예요).
- 서울 기준이라 실제 접속 지역의 날씨와는 달라요.

### 썩은 통나무 던전
- 식구 한 마리를 골라 입장해요(하루 **3번**). 입장할 때 레벨·장비를 반영해 능력치를 한 번 굴려서 런이 끝날 때까지 써요. 방·유물 제안·상점·이벤트는 런 시드로 정해져서 새로고침해도 바뀌지 않아요.
- **층 구성(100층 = 10장)**: 한 장은 10층이에요. 1층은 전투·이벤트·보물 중에서, 나머지 층은 방 3개 중에서 골라요(같은 종류는 한 층에 하나). 한 장의 4층과 9층에는 휴식처가 꼭 있고, **5층은 엘리트, 10층은 장 보스** 하나뿐이에요(100층은 마지막 보스). 전투·엘리트 방은 적 계열과 전투 환경이 미리 보여서 상성을 보고 고를 수 있어요.
- **전투**: 일반 전투는 기본이 자동으로 끝까지 싸우는 방식(상성·환경 적용)이고, 방을 고르는 화면의 **⚔️ 자동 / 🎮 직접 전투** 선택으로 **일반 전투도 매 턴 행동을 골라 직접** 할 수 있어요(공격·방어 태세·일격·회복·계열 기술, 패턴 예고는 없고 보상·회복은 자동 전투와 똑같아요; 고른 방식은 브라우저에 기억해요). 엘리트·보스는 언제나 보스 패턴이 붙는 **직접 전투**예요(계열 기술도 써요). 전투를 이기면 최대 HP의 10%를 회복해요. 후반 엘리트는 패턴이 2개(55층부터), 보스는 3개(60층부터)예요.
- **장 보스**: 10·20·…·90층 보스를 이기면 런이 이어져요. 공격·방어·최대 HP가 각각 **+4%**(런 내내, 쌓여요) 오르고, 최대 HP의 50%를 회복하고, 희귀·에픽 유물 중에서 하나를 골라요(에픽 60%). **100층 보스를 쓰러뜨려야 완주**예요.
- **방 6종**: ⚔️ 전투(유물 제안) · 💀 엘리트(좋은 유물) · 🏕️ 휴식처(HP 35% 회복, 또는 공격·방어·체력 하나를 +10.92% 단련) · 🛒 상점(🍄 버섯조각으로 유물·회복약) · ❓ 이벤트 6종(선택에 따라 달라져요) · 💎 보물(희귀 이상 유물 중 선택).
- **유물 17종**(일반 5·희귀 7·에픽 5): 능력치(공격·방어·HP; 유물·단련으로 늘어나는 이 효과는 **×1.82**(1.3 × 1.4)가 곱해진 값이에요 — 예: 날카로운 더듬이 +12% → +21.84%, 단련 +6% → +10.92%. 이벤트·장 보스 보너스와 유리 송곳니의 HP 감소는 그대로예요), 전투 후 회복, 버섯조각 +40%, 상점 할인, 휴식 강화, 계열 기술 쉬는 시간 −1턴, 사자의 심장·오래된 화석 같은 복합 효과, **두 번째 껍질**(쓰러지면 한 번 HP 50%로 부활), 네잎클로버(제안 +1), 유리 송곳니(공격 +72.8%, HP −15%). 100층을 오르는 동안 유물이 모자라지 않게 **같은 유물을 겹쳐 가질 수 있고**(능력치 유물 3개·희귀 2개 등 유물마다 최대 개수가 정해져 있고 효과가 개수만큼 쌓여요), 최대 개수까지 쌓은 유물은 더 나오지 않아요. 한 번만 가질 수 있는 유물(두 번째 껍질·네잎클로버·유리 송곳니·상인의 휘장)도 있어요. 얻은 유물은 **유물 도감**에 남아요.
- **유물 얻는 길**: 일반 전투는 이길 때 60% 확률로만 유물을 제안해요(아니면 버섯조각 +20). 엘리트·보물·이벤트·장 보스·상점은 그대로예요. 제안은 시드로 정해져서 새로고침해도 같아요.
- **버섯조각**: 이번 런 안에서만 쓰는 돈이에요(전투 승리로 얻고, 런이 끝나면 사라져요). 전투 한 번에 `10 + 10×층`이고 10층 이후로는 110으로 그대로예요(깊이 들어가도 상점이 너무 싸지지 않게).
- **적 능력치**: 일반 적의 공격·방어·HP는 **층마다 모든 난이도에서 똑같이 6.5%씩(복리)** 늘어요(`기본 × 1.08^(시작 스테이지-1) × 1.065^(층-1)`). 그 층의 **엘리트는 일반 적의 ×1.4, 보스는 ×1.8**이에요(세 능력치 모두). 100층 적은 1층 적의 약 510배(보스는 약 917배)예요.
- **난이도**: 쉬움 · 보통 · 어려움 · 매우 어려움 · 지옥. 난이도끼리는 1층의 시작 강함(서바이벌 스테이지로 1 / 9 / 17 / 25 / 33 — 8씩 벌려서 난이도 하나당 약 10층, 한 장 차이)과 보상 배율(×1 / ×1.5 / ×2 / ×3 / ×4)만 달라요. 식구의 힘에 맞는 난이도를 골라요. 시뮬레이션(서바이벌 평균 도달 스테이지 16~46인 식구) 기준 도달 층 중앙값: 약한 식구 39 / 19 / 4 / 2 / 1, 최상위 식구 69 / 59 / 49 / 39 / 29(쉬움 / 보통 / 어려움 / 매우 어려움 / 지옥)이고 100층 완주자는 없었어요(잘 싸운 경우라서 실제로는 더 어려워요).
- **보상**: 깬 층마다 골드 `40 + 25×min(층,10) + 12×max(0,층-10)`·경험치 `10 + 4×min(층,10) + 2×max(0,층-10)`(완주하면 ×1.5, 난이도 배율 곱; 쉬움 100층 완주 ≈ 115,000 G). 처음 넘는 층 보상: 최고 기록을 처음 넘어서며 지난 **10·25·50·75·100층**마다 💎 3 / 3 / 5 / 8 / 20(어려운 난이도 기록이 있으면 쉬운 난이도로는 못 받아요). 하루 첫 완주는 💎 2, 평생 첫 완주는 전설 장비 하나.
- **문지기**: 식구 하나를 던전 문지기로 세우면(언제든 바꾸거나 내릴 수 있어요), 다른 유저의 던전에서 엘리트 층(5·15·…·95층) 중 약 40%에 그 문지기가 서요(런을 시작할 때 정해지고, 문지기를 세운 유저가 있어야 해요; 내 문지기는 내 던전에 나오지 않아요). 문지기는 그 층 엘리트와 같은 능력치·패턴으로 싸우고 그 식구의 계열을 따라요. 도전자가 이기면 **현상금**(이긴 층 × 300 G × 난이도 배율 + 💎 1, 다이아는 하루 5개까지)과 평소 엘리트 보상을 받고, 지면 문지기 주인에게 **통행료**(쓰러진 층 × 2,000 G × 난이도 배율, 주인이 하루 10번까지)가 쌓여요. 통행료와 현상금은 시스템이 주는 돈이라 도전자가 잃는 것은 없고 서로 짜고 돈을 옮길 수도 없어요. 쌓인 통행료는 `POST game-state/dungeon/guardian/claim`으로 받아요(다른 유저가 쌓는 값이라 원자적 갱신으로만 쓰고, 주인의 저장이 덮어쓰지 않아요).
- **순위**: 가장 높이 오른 난이도·층 순, 같으면 완주 횟수 순이에요(어려운 난이도의 1층이 쉬운 난이도의 100층보다 높아요). 기록은 `난이도 번호 × 1000 + 층`으로 저장하고, 10층 시절의 옛 기록(`× 100`)은 읽을 때 자동으로 변환해요(DB는 그대로).
- **10층 시절과의 호환**: 진행 중이던 런은 그대로 이어지고(10층 보스를 이기면 2장으로 넘어가요), 적 강함은 새 난이도 곡선을 따라요.

### 현상수배 보스
- 매일(한국 날짜) **수배서**가 한 장 붙어요. 오늘의 수배 보스(종·전투 환경)와 **출전 조건**(1~2개)은 날짜에서 정해져서 모두에게 같아요. 조건: 특정 계열만 / 희귀도 제한(일반만·희귀 이하·에픽 이하) / 장비 사용 금지 / 전투 레벨 제한(20·30·40) / 행동 금지(회복·강력한 일격·계열 기술 중 하나).
- **동·은·금** 세 등급 중 골라 **직접 전투**로 도전해요. 보스 능력치는 식구 힘과 상관없는 절대값(서바이벌 스테이지 8 / 20 / 32의 엘리트 공식 `기본 × 1.08^(스테이지−1) × 엘리트 배율`)이고 패턴이 1 / 2 / 3개 붙어요(오늘의 패턴 순서에서 앞에서부터). 조건이 식구 힘을 깎으면(장비 금지·레벨 제한·희귀도 제한) 그만큼 어려워져요. 시뮬레이션 기준 일반 Lv20은 동, 희귀 Lv40은 은, 전설 Lv50 정도부터 금이 가능해요.
- 도전은 하루 **3번**(시작할 때 1번씩 쓰고, 지거나 포기해도 돌아오지 않아요). 이긴 등급은 그날 **현상금**(동 50,000 G + 💎1 / 은 150,000 G + 💎2 / 금 400,000 G + 💎4)을 한 번만 받아요. 리듬 일격과 계열 기술도 쓸 수 있어요(금지 조건이 없다면).
- **수배서 도감**: 이긴 날의 수배서(보스 종 + 가장 높게 깬 등급)가 도감에 남고, 깬 장 수가 3·7·14·30·60·100장에 처음 닿을 때 💎 2·5·8·15·30·50개를 받아요. 날짜가 바뀌면 오늘의 도전·깬 등급만 초기화돼요. 어제 시작해서 남은 전투는 접혀요.
- API: `GET game-state/wanted` · `POST game-state/wanted/{start, act, forfeit}`. 규칙은 `game-state/wanted-engine.ts`, 상태 진행은 `wanted.service.ts`(GameStateService의 공용 도우미를 써요).

### 전투 레벨 각성 ★
- 전투 레벨이 **25 이상**인 식구를 **골드와 다이아**로 각성하면 전투 레벨(경험치)이 **1로 돌아가는 대신 영구 ★가 1개** 붙어요(배틀 ▸ 전투 레벨 각성 ★). ★ 하나마다 **HP·공격력·방어력 +20%**이고 장비 보너스와는 **곱해져요**(`(1+장비)(1+★)−1`), 최대 ★5(+100%). 종을 합치지 않고 제자리에서 강해지는 방식이라 종 승급 합성과는 달라요. 전투 레벨 상한이 원래 없어서 '각성 가능 레벨 25'를 기준으로 삼았어요(레벨이 25를 넘어도 각성할 수 있고, 남은 경험치는 버려져요).
- 비용(종 희귀도 일반~신화): ★1 골드 100만·200만·400만·800만·1600만, ★n은 ×3^(n−1)(★5는 ×81), 다이아는 ★1이 20·40·80·150·300개이고 ★n은 ×n. 예) 신화 종 ★5는 약 20억 G·💎1500. 각성한 식구는 낮은 레벨에서 다시 올라와야 해서, 레벨 25를 다시 채우는 것이 장기 목표예요(레벨 1→25에 약 1.7만 전투 경험치). 진행 중인 전투·던전은 시작할 때 굴린 능력치를 그대로 써요.
- ★ 보너스는 `GameStateService.battleBonuses(gameState, speciesId)`가 장비 보너스에 곱해서 야생 배틀·보스 타워·서바이벌·던전(입장할 때 굴리는 능력치)에 넣고, **현상수배**에는 레벨 제한 조건으로 레벨이 깎이지 않았을 때만 적용돼요(장비 금지 조건은 ★와 무관). 장비 영향을 줄인 **투기장**과 레벨로만 겨루는 **하극상 대회**에는 적용되지 않아요. 화면의 식구 고르기 카드 이름 옆에 ★가 붙고 능력치 미리보기에도 반영돼요(프론트 `gameCalc.ts`의 `starBonuses/combineBonuses`가 서버와 같은 값이고 테스트로 비교해요).
- 저장: GameState `battleStars`(Map, 종 id → ★ 개수). API: `GET game-state/awaken`, `POST game-state/awaken {speciesId}`(키우는 종만, 레벨·골드·다이아 확인 뒤 경험치 0·★ +1).

### 떠돌이 상인
- 매일 다른 **한정 재고**를 파는 상인이 와요(내 월드 ▸ 떠돌이 상인). 재고는 날짜로 정해져 모두 같고(`merchant-engine.ts`의 `merchantLotsFor`), 4칸이에요: **🎟️ 숲 탐색권**(기준 3만 G, 하루 3개) · **🔩 장비 조각 25개 묶음**(7만 5천 G, 하루 2개) · **부스트 2시간**(종류는 날마다 달라요, 기준 = 내 시간당 최대 수익 기준 부스트 1시간 가격 × 2, 하루 1개) · **희귀 장식**(그날 이벤트 기간이 아닌 계절 한정 장식, 기준 = 상점가 × 1.5, 하루 1개). 하루에 한 칸은 **특가**(가격 −20%, 살 수 있는 개수 +1)예요. 한정 개수는 한 사람이 하루에 살 수 있는 수라서 오늘 안 사면 사라져요.
- 가격 = 기준 × (달 배율 × 날씨 배율, 0.7~1.3배로 제한) × (특가면 0.8), 100 G 단위 반올림. **달의 위상**은 한국 날짜로 계산하고(기준 신월 2000-01-06, 주기 29.53일), 품목마다 가장 비싸지는 위상이 달라요(탐색권 보름 · 조각 신월 · 부스트 상현 · 장식 하현, 진폭 ±12%). **날씨 배율**은 품목마다 달라요(예: 비 오는 날 탐색권 −8%·장식 +10%, 눈 오는 날 조각 +8%·장식 −10%). 날씨는 그날 상인을 **처음 본 시점의 숲 날씨로 하루 동안 고정**돼요(`merchant_days`, 10일 뒤 삭제). 날씨 정보가 없으면 달만 따라요. 화면에는 기준 대비 %와 '싸게 나왔어요/비싸요/특가' 표시가 나와요.
- 부스트는 24시간까지만 쌓이고 장식은 이미 가졌으면 못 사요. 구매 기록은 GameState `merchant{day,bought}`(날짜가 바뀌면 처음부터)예요. API: `GET game-state/merchant`, `POST game-state/merchant/buy {itemId, count?}`.

### 표본 전시관
- **키우고 있는 종**의 표본을 골드로 만들어 전시관에 진열해요(내 월드 ▸ 표본 전시관). 표본 등급은 **동 → 은 → 금 → 화석** 순이고, 같은 종을 또 만들면 한 단계씩 올라가요. 값 = 종 희귀도별 동표본 값(일반 2천 · 희귀 1만 · 에픽 5만 · 전설 25만 · 신화 150만 G) × 등급 배율(1·4·16·64)이며, 올릴 때는 **다음 등급 값만** 들어요(신화 화석 표본까지 합계 약 1.275억 G). 낸 골드는 돌려받지 않아요.
- **선반(진열 칸)**은 기본 6칸이고 골드로 +2칸씩 최대 7번(20칸)까지 늘려요(값 15만 × 2^단계). 진열한 표본의 **전시 점수** = 등급 점수(동 1 · 은 3 · 금 8 · 화석 20) × (1 + 종 희귀도) 합계이고, 점수 순으로 **전시관 순위**(`GET leaderboard/exhibition`, 사육장을 비공개로 한 유저는 제외)가 매겨져요. 신화 종의 금·화석 표본이 자랑거리예요.
- 진열한 표본은 **사육장 방문 화면**에 전시관으로 보이고(`VisitResult.exhibition`), 방문자가 **전시관 좋아요**를 눌러요. 좋아요는 사육장 좋아요와 같은 저장소(`terrarium_likes`)에 `terrariumId='exhibition'`으로 쌓여서 받은 좋아요 합계·순위·업적·푸시 알림·최근 좋아요(“표본 전시관”)에 함께 반영돼요. 진열한 표본이 있을 때만 누를 수 있어요.
- 저장: GameState `exhibit{specimens(종 id→등급), shown(진열 순서), shelfLevel, score}`(진열을 바꿀 때마다 점수를 다시 계산해 저장). 규칙은 `exhibit-engine.ts`, 현황·제작·진열·선반은 `exhibit.service.ts`. API: `GET game-state/exhibit`, `POST game-state/exhibit/craft|display|shelf`.

### 사육장 관리인 고용
- 월급을 **골드로 매일** 내면 NPC 관리인이 **자동 급식·분무**(자동 급식기·분무기와 같은 효과), **수익 수령**(모은 수익을 틱마다 골드로 받아 줘요)을 대신 해 주고 **자동 수익이 조금 늘어요**(내 월드 ▸ 사육장 관리인). 등급: 견습(수익 +2%) · 숙련(+4%) · 베테랑(+6%) · 명인(+8%).
- **하루 월급 = 내 시간당 최대 수익 × 1·2·4·8시간**(천 단위 반올림, 최소 월급 5천·2만·6만·20만 G)이라 경제 규모에 맞춰 오르고, 월급이 늘어나는 수익보다 많아서 시간 대신 돈을 쓰는 편의 서비스예요. 고용할 때 첫날 월급을 바로 내고, 이후 **날짜(한국 시간)가 바뀐 뒤 처음 접속(틱)할 때** 지난 날수만큼 한꺼번에 나가요(접속하지 않아도 날짜는 가요). 모아 둔 수익을 먼저 받아서 월급에 쓰고, **골드가 모자라면 낼 수 있는 일수만 내고 관리인이 떠나요**(다시 고용할 수 있어요). 오래 비워도 최대 30일치만 나가고 그보다 오래된 날은 없던 일이 돼요. 등급을 바꾸면 새 월급을 다시 내고(낸 월급은 환불 없음), 내보내기 전에 일한 날의 월급은 정산해요.
- 구현: `manager-engine.ts`(등급표·월급 공식), GameState `manager{grade,hiredAt,paidThrough,totalPaid}`, `GameStateService.settleManager`(advance 시작에서 정산·효과 여부 결정)·`managerCollect`(틱 끝에서 수령), `manager.service.ts`(현황·`hire`·`dismiss`). 일시정지 계정은 월급도 효과도 없어요. API: `GET game-state/manager`, `POST game-state/manager/hire {grade}`, `POST game-state/manager/dismiss`.

### 장비 각인 재련소
- 장비에 능력치 말고 **특수 효과 한 줄(각인)**을 새겨요(내 월드 ▸ 장비 각인 재련소). 장비마다 **골드와 장비 조각**을 내고 굴리면 무작위 각인(종류 + 등급)이 나오고, 마음에 들면 **교체하기**, 아니면 **버리기**(기존 각인 그대로)를 골라요. 보류 중에 또 굴리면 새 각인으로 덮어쓰고 값을 또 내요 — 원하는 각인이 나올 때까지 계속 굴릴 수 있는 끝없는 소비처예요.
- 굴리는 값(장비 희귀도 일반~신화): 골드 3만·10만·30만·100만·300만 G, 조각 3·8·20·50·120개(참고: 복사본 1개를 분해하면 조각 4·10·25·60·150개). 종류(비중): **⚔️ 상성 연마**(30%, +1/2/3/4%p) · **⏩ 기술 단련**(20%, 쉬는 시간 −1/−1/−1/−2턴) · **💗 회복 각인**(25%, +3/5/8/12%p) · **📘 경험 각인**(25%, +2/3/5/8%). 등급: 일반 55% · 희귀 30% · 영웅 12% · 전설 3%(값이 위 순서의 1~4번째).
- 효과는 **장착 중인 장비(같은 장비는 한 번만)**의 각인만 더해지고 종류마다 합계 상한이 있어요(상성 8%p · 기술 3턴 · 회복 20%p · 경험 30%). 상성 연마는 **상성이 유리할 때만** 야생 배틀·보스 타워·던전·현상수배(장비 허용 조건일 때)의 공격·방어 보정에 더해져요(서바이벌 제외, `describeBattleRules`/`applyBattleRules`의 `matchupExtra`). 기술 단련은 `duelSkillOf`에서 연구소·던전 유물 감소분과 합쳐져 모든 직접 전투에 적용돼요. 경험 각인은 `boostXp`(전투 경험치 부스트와 곱해져요), 회복 각인은 던전 전투 후 회복 비율에 더해져요. 던전은 입장할 때의 장착 상태를 런에 고정해요(`run.lab.engMatchup/engPostHeal`).
- 저장: 장비 하나(`EquipmentItem`)에 `engraveKind/engraveGrade`(현재), `pendingKind/pendingGrade`(보류). 옛 장비는 필드가 없어도 각인 없음으로 동작해요. API: `GET game-state/engrave`, `POST game-state/engrave/roll|accept|discard {itemId}`.

### 계열 기술 연구소
- 불꽃·숲·서리 **3계열마다 별도의 연구 트리**로 직접 전투의 계열 기술(불길·뿌리 감기·빙결)을 강하게 해요(배틀 ▸ 계열 기술 연구소). 골드와 다이아로 올리고 단계마다 값이 기하급수로 올라요(`skillLabCost`: 1단계 골드 × 성장률^(단계−1), 다이아 = 기본 × 단계). 올리면 진행 중인 직접 전투에도 다음 행동부터 바로 적용돼요.
- 불꽃: **🔥 불씨 증폭**(5단계, 화상 피해 +10%/단계, 40만 G부터 ×1.8) · **🕯️ 오래 타는 불**(1단계, 화상 +1턴, 600만 G·💎30) · **⏩ 불꽃 가속**(1단계, 불길 쉬는 시간 −1턴, 1000만 G·💎50). 숲: **🌿 뿌리 강화**(5단계, 속박으로 줄어드는 공격력 +2%p/단계) · **🪢 질긴 뿌리**(속박 +1턴) · **⏩ 뿌리 재생**(쉬는 시간 −1턴). 서리: **❄️ 한기 응축**(5단계, 빙결의 공격 피해 +4%p/단계) · **⏩ 서리 가속**(2단계, 빙결 쉬는 시간 −1턴/단계, 300만·900만 G).
- 연구는 **그 계열 식구가 쓰는 계열 기술에만** 적용되고(자동 전투·투기장에는 계열 기술이 없어요), 야생 배틀·보스 타워·서바이벌·던전·현상수배의 직접 전투에서 모두 효과가 나요. 서버가 `GameStateService.duelSkillOf(species, gameState, 추가 감소분)`에서 연구 효과(`lab`)와 쉬는 시간 감소(`cooldownReduce`, 던전 유물 감소분과 합산, 최소 1턴)를 계열 기술에 넣고 `playDuelTurn`/`getDuelSkillInfo`가 읽어서, 행동 목록의 기술 설명(턴 수·%·쉬는 시간)도 연구에 맞게 바뀌어요. 저장: GameState `familyLab`(Map). API: `GET game-state/skill-lab`, `POST game-state/skill-lab/upgrade {id}`.

### 던전 연구소
- 런이 끝나면 사라지는 버섯조각과 달리, **골드와 다이아로 던전을 영구히 강화**해요(던전 화면의 '🔬 던전 연구소'). 연구 6종: **🔎 유물 감정실**(1단계, 유물을 고를 때 제안이 1개 늘어요) · **🏪 상점 창고**(1단계, 떠돌이 상점 유물 재고 +1) · **❤️ 체력 단련장**(5단계, 입장할 때 HP +2%/단계) · **🏕️ 야영 장비**(5단계, 휴식 회복량 +2%p/단계) · **🍄 보급 창고**(5단계, 시작 버섯조각 +10개/단계) · **🏷️ 단골 거래처**(5단계, 떠돌이 상점 가격 −5%/단계).
- 값은 단계마다 기하급수로 올라가요(`dungeonLabCost`): 골드는 1단계 값에 단계마다 ×1.8~1.9(천 단위 반올림), 다이아는 `기본 × 단계`. 예) 체력 단련장 30만→57만→108.3만→205.8만→391만 G(💎 2·4·6·8·10), 감정실 800만 G·💎40, 창고 500만 G·💎25. 전부 올리면 수천만 G 규모의 소비처예요.
- 효과는 **입장할 때** 정해져 그 런이 끝날 때까지 유지돼요: 시작 HP·시작 버섯조각은 입장 순간 적용하고, 감정실·창고·야영·거래처 단계는 런에 저장(`run.lab`)해서 `getDungeonStats`/`rollShop`이 읽어요. 던전 도중에 올려도 진행 중인 런에는 영향이 없고 다음 입장부터 적용돼요(예전 런·옛 계정은 연구 0단계로 동작). 늘어난 상점 재고는 기존 3개 뒤에 붙어서 앞의 3개는 그대로예요. 저장: GameState `dungeonLab`(Map). API: `POST game-state/dungeon/lab {id}`, 현황은 던전 `info.lab`.

### 던전 출정 준비물
- 썩은 통나무 던전에 **입장하기 전에** 골드나 다이아로 사는 **일회용 보급품**이에요(던전 화면의 '🎒 출정 준비물'). 이번 입장에서만 쓰고 런이 끝나면 사라져서, 영구 효과와 달리 입장할 때마다 돈이 나가요(하루 3번 입장). 종류와 한 번에 살 수 있는 최대 개수: **🎁 유물 상자**(1개, 입장하자마자 보물 상자급 유물 3개 중 하나 고르기 — 건너뛰면 버섯조각 30) · **🍄 버섯조각 주머니**(3개, 하나당 시작 버섯조각 +40) · **🗺️ 정찰 지도**(3개, 쓰면 앞으로 3개 층의 방 구성을 미리 봐요) · **🔄 방 새로고침**(3개, 이번 층의 방 3개를 다시 굴려요 — 엘리트·보스 층은 안 돼요).
- 가격: 골드는 기본 40만/8만/6만/5만 G에 **난이도 보상 배율**(1·1.5·2·3·4)을 곱하고, 다이아는 난이도와 상관없이 3/1/1/1개예요. 골드로 낼지 다이아로 낼지 입장할 때 고르고(한 번에 한 가지로 전부 계산), 모자라거나 이미 진행 중인 던전이 있거나 오늘 입장 횟수를 다 썼으면 값이 나가지 않아요(저장하기 전까지 차감이 반영되지 않음). 유물 상자·버섯조각은 입장하는 순간 적용되고, 정찰 지도와 방 새로고침은 런 중 방 고르기 화면에서 개수만큼 써요(`POST game-state/dungeon/scout`, `POST game-state/dungeon/reroll`).
- 방은 (런 시드, 층, 굴림 번호)로 정해져서 정찰로 본 방은 실제 방과 같아요. 새로고침은 그 층의 굴림 번호만 올려서 다시 굴리고(`run.rerollFloor/rerollVariant`) 다른 층에는 영향이 없어요. 서버가 층의 방 구성을 항상 다시 계산하므로 화면의 방 번호와 어긋나지 않아요. 입장 요청은 `supplies`(`{relic, mushrooms, scout, reroll}`, 선택)와 `pay`('gold'|'diamond')를 받고 서버가 최대 개수로 잘라요.

### 매일 경매
- 매일 서버가 희귀한 물건 **3개**를 경매에 올려요(내 월드 ▸ 매일 경매): ① 전설·신화 **장비** 1개(신화 40%) ② 지금 이벤트 기간이 아닌 **계절 한정 장식** 1개(상점에서 못 사는 것을 경매로 구해요) ③ **12시간 부스트** 1개. 물건은 날짜로 정해져(`auction-engine.ts`의 `auctionLotsFor`) 같은 날엔 모두 같고, 처음 여는 사람이 `auction_lots`(날짜×번호, 60일 TTL)에 저장해요. 시작가는 장비 60만(신화 240만) G · 장식 상점가 ×2 · 부스트 30만 G예요.
- 입찰하면 **그 자리에서 골드가 보관(차감)**돼요. 더 높게 입찰하면 최소 `현재가 + 5%`(천 단위 올림, 최소 1,000 G)여야 하고, 내가 최고가일 땐 올린 만큼(차액)만 더 보관돼요. 밀리면 입찰금이 환불 기록으로 남아 **받기**를 누르면(또는 다음 입찰 때 자동으로) 돌아와요. 입찰가·입찰자는 모두에게 공개돼요. **한국 시간 자정에 마감**해 최고가 입찰자가 낙찰받고, 마감 뒤에 **모두 받기**로 낙찰품을 받아요(60일 안에). 낙찰금은 사라지는 골드이고 유저끼리 물건·골드를 주고받지 않아요.
- 안전장치: 최고가를 바꾸는 갱신은 "내가 본 최고가 그대로일 때만" 적용되는 비교 후 교환(CAS)이라 동시 입찰이 와도 한 명만 이겨요(진 쪽은 보관금이 되돌아와요). 밀린 입찰의 환불 기록은 최고가가 바뀌는 **같은 갱신 안에서** 함께 남기고, 환불·낙찰품 지급은 "받음" 표시를 먼저 바꾸면서(읽으면서 변경) 해서 두 번 받을 수 없어요. 낙찰한 장식을 그사이 이미 가졌다면 낙찰금을 돌려줘요. 어제의 낙찰 결과는 경매 화면과 숲 신문에 실려요. API: `GET game-state/auction`, `POST game-state/auction/bid {lot, amount}`, `POST game-state/auction/claim`.

### 오늘의 운세
- **하루(한국 시간) 한 번** 운세를 뽑아요(내 월드 ▸ 오늘의 운세). 등급은 **대길 5% · 중길 20% · 소길 45% · 말길 30%**이고 흉은 없어요. 결과는 유저 id와 날짜로 정해서 같은 날엔 늘 같아요(`fortune-engine.ts`의 `drawFortune`). 뽑는 순간 등급에 따른 선물(대길 100,000 G·💎2·🎟️1 / 중길 50,000 G·💎1 / 소길 25,000 G / 말길 10,000 G)이 들어오고, **행운 계열**(불꽃·숲·서리 중 하나)·행운의 색·숫자·오늘의 한마디가 정해져요.
- 그날 자정(한국 시간)까지 행운 계열의 **번식 진행이 +10/7/5/3%**(대길/중길/소길/말길) 빨라지고 숲 탐색·원정에서 그 계열 종이 **×2/1.6/1.4/1.2** 더 잘 나와요. 번식은 `advance()`가 단계(5초)마다 그 시각이 운세의 날짜 안일 때만 곱하고(자정을 가로지르는 구간은 그날 부분만), 탐색은 `exploreFamilyWeights(gameState)`가 날씨·계절 이벤트와 함께 곱해요. 8시간을 넘는 자리 비움 구간엔 적용하지 않아요(날씨와 같아요).
- **7일 연속**으로 뽑으면 7일마다 보너스(💎3·🎟️2)가 추가돼요. 하루를 거르면 연속 일수가 1부터 다시 시작하고 최고 기록은 남아요. 아직 안 뽑았으면 사육장 화면에 안내 배너가 떠요. 저장: GameState `fortune{day,gradeId,family,color,number,line,streak,best}`. API: `GET game-state/fortune`, `POST game-state/fortune/draw`.

### 계절 이벤트 (절기·명절 한정)
- 실제 달력(한국 시간)의 **설날·벚꽃철(3/28~4/10)·장마철(6/24~7/25)·추석·할로윈(10/18~10/31)·크리스마스(12/18~12/26)**에 열려요(내 월드 ▸ 계절 이벤트). 설날·추석은 음력이라 서버가 `Intl`의 중국력으로 그해 양력 날짜를 구하고 그날의 앞 3일~뒤 2일을 열어요(오차가 ±1일 나도 되도록 여유를 둬요). 날짜는 DB가 아니라 `game-state/event-engine.ts`의 규칙이고, 이벤트마다 편드는 계열이 하나씩 있어요(불꽃: 추석·할로윈 / 숲: 벚꽃철·장마철 / 서리: 설날·크리스마스).
- 이벤트 기간에는 ① 숲 탐색·원정에서 같은 등급 안의 그 계열 종이 **×2** 더 잘 나와요(오늘의 숲 날씨가 같은 계열을 편들면 곱해져 ×4, 다른 계열이면 둘 다 ×2 — `GameStateService.exploreFamilyWeights()`가 합성하고 `pickWeightedByFamilyWeights`가 고르며, 이벤트가 없고 날씨 정보도 없으면 예전처럼 균등하게 골라요). ② **한정 장식**(이벤트마다 배경 희귀 1종 + 소품 에픽 1종, 12종, 번식 보너스·가격은 같은 등급의 일반 장식과 같아요)을 살 수 있어요. 기간이 아니면 서버가 구매를 거절하고(`DecorItem.eventId`), 산 뒤에는 계정에 영구히 남아 기간이 지나도 꾸미기에서 놓을 수 있어요. 그래서 '꾸미기 장식 25개'·'에픽 8개' 업적의 "전부 모으기"는 상시 판매 장식(25종·에픽 8종) 기준이에요. ③ 이벤트마다 **한 해에 한 번 선물**(30,000 G · 💎3 · 🎟️2)을 받아요(`seasonalGifts`에 '이벤트-년도'로 기록).
- API: `GET game-state/seasonal`(열린 이벤트·다가오는 이벤트·올해 일정표), `POST game-state/seasonal/gift {eventId}`. `GET decor`의 한정 장식에는 `eventName`과 지금 살 수 있는지(`available`)가 붙어요. 사육장 화면에는 열린 이벤트 배너가 떠요.

### 숲 복원 프로젝트
- 모든 유저의 **탐색·원정·배틀·던전**이 한 주(월~일) 동안 하나의 게이지에 점수로 쌓여요(커뮤니티 ▸ 숲 복원). 점수: 숲 탐색 +2, 원정 +5, 야생 배틀·투기장·보스 타워 승리 +2(패배 +1), 던전 5층마다 +1(최대 10). **한 사람이 하루에 쌓을 수 있는 점수는 50점**이라 혼자서 게이지를 채울 수는 없어요(상한을 넘는 행동도 횟수에는 세요).
- 주간 목표는 주가 시작될 때 한 번 정해서 그 주 내내 바뀌지 않아요: `min(지난 주 참여자 수 × 100, 지난 주 점수 × 1.1)`을 10 단위로 반올림하고 최소 300점이에요. 게이지가 목표의 **25·50·75·100·150%**를 넘으면 그 주에 접속하는 **모두가** 마일스톤 보상(골드·💎·🎟️ 탐색권)을 한 번씩 받을 수 있고(점수를 안 쌓아도 받아요), 내가 쌓은 점수가 30·100·250점을 넘으면 **개인 공헌 보상**을 따로 받아요. 지난 주에 못 받은 보상은 다음 주 화면에 '지난 주 못 받은 보상'으로 남아요. 게이지 단계는 🥀황폐한 숲 → 🌱새싹 → 🌿풀 → 🌳울창한 숲 → 🌸활짝 핀 숲(100%)으로 바뀌어요.
- 점수 적립은 `restoration-ledger.service.ts`(모델만 쓰는 적립기, `GameStateService`가 끝자리 옵션 인자로 받아 `contributeRestoration`으로 호출 — 못 쌓아도 게임은 그대로), 규칙·수치는 `restoration-engine.ts`, 화면용 정보·보상 받기는 `restoration.service.ts`예요. 컬렉션 `restoration_weeks`(주 게이지, `$inc`로 원자적 증가)·`restoration_entries`(주×유저, 하루 상한은 `dayPoints <= 상한−이번점수` 조건부 갱신으로 동시 요청에도 넘지 않아요, 받은 보상 id는 `$addToSet`+`claimed:{$ne}` upsert로 한 번만). API: `GET game-state/restoration`, `POST game-state/restoration/claim {id, last?}`.

### 숲 신문
- 어제 숲에서 있었던 일을 모아 **매일 한 호**가 나와요(커뮤니티 ▸ 숲 신문). 그날 처음 읽는 사람이 있을 때 서버가 어제(한국 시간)의 기록으로 만들어 `forest_news`에 저장하고(14일 뒤 삭제), 그날은 모두가 같은 호를 봐요. 기사는 ① 전설·신화 발견(희귀도 높은 순, 신화면 머리기사) ② 던전 최고 기록(난이도·층 기준 한 건)과 도전 횟수 ③ 수배 보스 금등급 검거자 ④ 미니게임 1등 모음(퍼즐·콩 달리기·콩 쌓기·이 콩 누구?·버섯 가게 + 참가자 수) ⑤ 어제 숲 날씨(가장 많이 관측된 날씨·기온 범위, `weather_logs`) ⑥ 오늘의 한마디예요. 자료가 없는 항목은 빠지고 아무 일도 없었으면 '조용한 하루' 기사가 나가요.
- 전설·신화 발견, 던전(5층 이상), 수배 금등급 검거는 일어날 때 `forest_events`에 한 줄 남겨요(10일 뒤 삭제, 기록 실패는 게임에 영향이 없어요). 나머지는 이미 있는 기록 컬렉션을 어제 날짜로 읽어요. API: `GET game-state/news`. 규칙(문장 만들기)은 `game-state/news-engine.ts`(순수 함수), 모으기·저장은 `news.service.ts`예요.

### 이 콩 누구?
- 실루엣이나 확대한 그림만 보고 어느 콩벌레인지 **보기에서 골라** 맞히는 연속 정답 퀴즈예요. **제한 시간은 처음 8초이고 맞힐 때마다 0.1초씩 줄어요**(최소 2초). 틀리거나 시간이 지나면 끝이고 점수는 연속으로 맞힌 개수예요. 연속 정답이 쌓일수록 어려워져요: 10개부터 그림이 확대되고, 15개부터 보기가 4 → 5개, 30개부터 6개로 늘고, 25개부터는 확대한 실루엣이 나와요. 틀린 보기는 처음엔 아무 종이지만 갈수록 정답과 같은 계열·희귀도의 닮은 종이 많이 섞여요. 같은 판에서는 되도록 같은 종이 나오지 않아요. 키보드 1~6으로도 골라요.
- **정답과 채점은 서버가 해요.** 화면에는 보기와 그림 주소만 가요. 그림 주소(`/api/quiz-image/<토큰>`)는 종 id와 만료 시각을 AES-256-GCM으로 암호화한 일회용 토큰이라 주소만 봐서는 종을 알 수 없고 2분 뒤 만료돼요(로그인 없이 `<img>`가 직접 부르므로 인증 대신 토큰으로 막아요). 실루엣·확대는 화면의 CSS로 처리해요(서버에 이미지 처리 라이브러리가 없어서 원본 그림을 그대로 내려 줘요 — 마음먹고 그림을 대조하는 부정 행위까지는 막지 못하지만 보상은 평생 한 번씩이라 작아요). 문제를 낸 뒤 300ms 안에 온 답은 사람이 읽고 고른 것이 아니라서 받지 않고, 제한 시간+1.2초가 지나면 맞는 답이어도 시간 초과예요. 문제를 낸 채 끊긴 판은 조회·새 시작 때 그 연속 정답으로 끝난 것으로 정리해요.
- 순위는 오늘 가장 길게 이어서 맞힌 순(같은 개수는 같은 순위, 먼저 달성한 사람 위)이고 한국 시간 자정에 새로 시작해요(`quiz_records`, 45일 뒤 삭제). 평생 최고 연속 정답이 처음 닿을 때 보너스를 한 번씩 받아요: 10연속 🎟️1 · 20연속 💎1 · 30연속 💎2 · 50연속 💎3.
- API: `GET game-state/quiz` · `POST game-state/quiz/{start, answer}` · `GET quiz-image/:token`(공개) · `GET leaderboard/quiz`. 그림 폴더는 기본 `frontend/public`(환경 변수 `QUIZ_ASSET_DIR`로 바꿀 수 있어요).

### 버섯 가게 운영
- 하루 장사를 계획하는 경영 미니게임이에요. **표고(원가 20·기준가 40) · 느타리(12·25) · 송이(60·180)** 세 가지에 대해 **판매 가격**(기준가의 50~250%)과 **준비할 개수**(0~500)를 정하면, 서버가 그날의 손님 수를 계산해 팔린 만큼 매출을 내고 남은 재고는 상해서 버려요. 준비 비용(원가 × 개수의 합)은 **밑천 2,500**을 넘을 수 없어요.
- 손님 수 = `기준 수요 × 날씨 배율 × 그날 변동(0.9~1.1) × (기준가 ÷ 가격)^민감도`. 기준 수요는 60 / 90 / 20명이고 가격 민감도는 보통(1.6) / 민감(2.2) / 둔함(1.25)이에요(화면에는 단계만 보여요). 오늘의 **실제 숲 날씨**(맑음·흐림·비·뇌우·눈·폭염·한파)가 버섯마다 손님 수를 달리해요(비: 표고 ×1.3·느타리 ×1.1·송이 ×0.8, 폭염: ×0.85·×0.8·×0.7 등). 날씨는 그날 처음 조회한 순간의 값으로 하루 고정되고 변동은 날짜로 정해져서 **모두에게 조건이 같아요**.
- **정식 영업은 하루 한 번**: 점수는 이익을 **그날 가장 잘 짠 계획의 이익으로 나눈 효율(%)**이에요(최적 계획은 서버가 가격 조합 전체를 훑어 구하고 결과에 함께 보여 줘요). 효율 **50 / 70 / 85 / 95%**에 닿은 단계의 보상을 모두 합쳐 받아요: 10,000 G · 20,000 G+🎟️1 · 30,000 G+💎1 · 50,000 G+💎2(최대 110,000 G · 🎟️1 · 💎3). 순위는 효율 → 이익 순이에요. **연습 영업**은 날씨·변동이 무작위인 가상의 하루라 마음껏 해 볼 수 있고 기록·보상은 없어요.
- API: `GET game-state/shop-sim` · `POST game-state/shop-sim/run`(`{ plan: [{productId, stock, price} × 3], practice? }`). 규칙은 `game-state/shop-sim-engine.ts`, 기록은 `shop_sim_records`(하루 한 건, 30일 뒤 삭제)·`shop_sim_days`(그날의 날씨)예요.

### 콩 쌓기 "흔들흔들 통나무 탑"
- 좌우로 움직이는 통나무(내보낸 콩벌레가 위에 앉아 있어요)를 **알맞은 때에 떨어뜨려** 탑을 쌓는 게임이에요. 아래 칸과 **겹친 만큼만 남고** 삐져나온 부분은 잘려요. 위치 차이가 허용치 이내면 **✨ 퍼펙트**(아래 칸에 딱 맞게 붙고 너비가 그대로, 퍼펙트가 3번 이어지면 너비가 10 늘어나요, 처음 너비 360이 최대). 하나도 안 겹치면 끝이에요(넓을 때는 항상 걸쳐서 끝나지 않고, 좁아져야 놓쳐요). 점수는 쌓은 칸 수이고 150칸이면 완주예요. 스페이스·↓·S, 화면 탭, ⬇️ 버튼으로 떨어뜨리고, '여기서 그만하기'로 지금까지의 기록으로 끝낼 수 있어요.
- 통나무는 3칸마다 틱당 속도가 1씩 빨라져요(5 → 17). 콩벌레의 **희귀도마다 퍼펙트 허용치**가 달라요(일반 ±6 · 희귀 ±7 · 에픽 ±8 · 전설 ±9 · 신화 ±10). 통나무가 나오는 위치(시드)와 속도는 희귀도와 무관하게 같아요. 시뮬레이션 기준 입력 오차가 ±50~100ms인 보통 플레이어는 11~20칸, ±25~33ms인 숙련자는 27~34칸을 쌓아요.
- **서버가 점수를 정해요**(콩 달리기와 같은 방식): 시작할 때 서버가 시드·희귀도·시작 시각을 적어 두고, 끝날 때 클라이언트는 **통나무마다 떨어뜨린 틱 수 목록**만 보내요. 서버(`stack-engine.ts`)가 초당 60틱의 정수 시뮬레이션을 처음부터 다시 돌려 칸 수를 계산하고(화면용 `frontend/src/utils/stack.ts`와 한 칸도 어긋나지 않아요), 실제로 흐른 시간+3초보다 긴 기록과 40분 넘은 판은 거절해요.
- 순위는 오늘 가장 높이 쌓은 순(같은 높이는 같은 순위, 먼저 달성한 사람이 위)이고 한국 시간 자정에 새로 시작해요(`stack_records`, 45일 뒤 자동 삭제). 보너스(하루 한 번씩, 오늘 최고 높이 기준): 8칸 🔩5 · 15칸 🎟️1+🔩5 · 25칸 🔩10 · 40칸 🔩10+💎1 · 60칸 💎2 — 하루 합계 🎟️1 · 🔩30 · 💎3.
- API: `GET game-state/stack` · `POST game-state/stack/{start, finish}` · `GET leaderboard/stack`.

### 하극상 대회
- **희귀도 '일반' 콩벌레만** 출전할 수 있는 주간(월~일, 한국 시간) 승점 대회예요. 이번 주에 출전할 일반 콩벌레를 하나 정하고(승점은 그대로 두고 언제든 바꿀 수 있어요), **장비 없이 전투 레벨과 개체 편차(±15%)**로 겨뤄요. 잘 안 쓰이는 일반 종이 주인공이에요.
- 경기는 서버가 자동 전투로 치러요. 상대는 같은 주에 출전한 다른 유저의 식구(그 순간의 레벨을 서버가 다시 읽어요)이고, 비슷한 승점의 출전자를 우선 보여 줘요. 출전자가 없으면 레벨이 내 80~100%인 **야생 선수**와 겨루고 승점이 절반이에요. 하루 **10경기**까지예요.
- 승점: 이기면 +20(나보다 레벨이 높은 사람을 이기면 레벨 차이만큼 최대 +10 더), 지면 −8(0 아래로는 안 내려가요). 이길 때마다 1,000 G를 받아요. 상대의 기록은 내가 도전해도 바뀌지 않아요.
- 주가 끝나면 **지난 주 순위 보상**을 받을 수 있어요(경기를 5번 이상 치러야 해요): 1위 300,000 G + 💎10 / 2위 200,000 G + 💎6 / 3위 150,000 G + 💎4 / 10위 이내 80,000 G + 💎2 / 참가상 20,000 G. 같은 승점·승수는 같은 순위예요.
- 저장은 `underdog_entries` 컬렉션(주 키 + 유저 한 건, 12주 뒤 자동 삭제)이고 API는 `GET game-state/underdog` · `GET …/opponent` · `POST …/{enter, match, claim}`예요. 규칙은 `game-state/underdog-engine.ts`, 진행은 `underdog.service.ts`예요.

### 사육장 꾸미기와 방문
- 장식은 **골드로 한 번 사면 계정에 영구히 남고**, 어느 사육장에든 무료로 옮겨 놓을 수 있어요. 배경(사육장마다 1개)과 소품(사육장마다 4칸, 같은 소품을 한 사육장에 두 개 놓을 수는 없어요)이 있어요.
- 장식은 계열(불꽃·숲·서리) 장식과 꾸미기 전용으로 나뉘어요. 계열 장식은 그 사육장에서 **같은 계열 종의 번식 진행**을 빠르게 해요(배경 +2/4/6%, 소품 +1/2/3%, 일반/희귀/에픽). 한 사육장·한 계열의 최대는 +12%예요. 번식 촉진 부스트와는 곱해지고, 8시간을 넘는 자리 비움(전설·신화 번식)에도 적용돼요.
- 가격(계열 장식): 배경 10,000 / 100,000 / 2,000,000 G, 소품 4,000 / 40,000 / 600,000 G. 꾸미기 전용은 절반이에요.
- **방문**: 누구나 `GET visit/:userId`로 공개 사육장의 장식·식구(종·마릿수)를 볼 수 있어요. 골드·다이아 같은 자원과 종 별명은 보이지 않아요. 설정에서 비공개로 하면 나만 볼 수 있고, 인기 사육장 순위에서도 빠져요.
- **좋아요**: 사육장마다 사람당 한 번(다시 누르면 취소)이에요. 내 사육장에는 누를 수 없어요. 받은 좋아요는 `terrarium_likes` 컬렉션을 세서 구하고, 좋아요 자체에 보상은 없어요. 순위는 모든 사육장의 합계예요.
- **좋아요 알림**: 새로 눌린 좋아요만 주인에게 푸시 알림(`terrariumLike` 설정으로 끌 수 있어요)과 화면 안 알림으로 알려요. 취소했다 다시 눌러도 같은 사람의 알림은 1시간에 한 번만 가요.
- **업적**: 장식 모으기(3/10/25개), 에픽 장식(1/4/8개), 한 사육장 전부 채우기(배경+소품 5칸), 받은 좋아요(5/20/50개), 누른 좋아요(3/15/40번). 좋아요는 지금 남아 있는 개수로 세서 취소·재클릭으로는 늘릴 수 없어요.

### 숲 탐색
- 첫 탐색 **500 G**, 탐색할 때마다 다음 비용이 **25 G씩 올라가요**(매일 초기화되지 않아요). 탐색권으로 한 탐색도 횟수에 포함돼요.
- **탐색권**은 골드로 살 수 없어요. 하루 1장 무료 충전(최대 5장까지), 일일 퀘스트·업적·우편 보상으로 얻어요. 탐색권을 쓰면 골드가 들지 않아요.

### 원정
- 가격은 **지금의 숲 탐색 비용(500 G + 25 G × 탐색 횟수)에 정확히 배수만큼 곱한 값**이에요. 탐색권으로는 갈 수 없고, 원정도 숲 탐색 한 번으로 세어져서 다음 탐색 비용이 올라가요. 한 번에 같은 종 2마리를 데려와요.

| 단계 | 가격 | 확률 |
|---|---|---|
| 원정 | 지금의 숲 탐색 비용 ×40 | 에픽 80% · 전설 17% · 신화 3% |
| 대원정 | 지금의 숲 탐색 비용 ×100 | 에픽 70% · 전설 22% · 신화 8% |

- **하루 횟수**: 원정은 하루 **5번**, 대원정은 하루 **3번**까지예요(둘은 따로 세고, 한국 시간 자정에 초기화돼요). 골드 부족·자리 부족처럼 실패한 시도는 횟수를 쓰지 않아요.
- **신화 천장**: 신화를 못 만난 채 다녀온 횟수가 29번이 되면 30번째 원정은 단계와 상관없이 신화가 확정이고, 신화가 나오면 천장은 처음으로 돌아가요.
- 뽑힌 등급에 아직 도감에 없는 종이 남아 있으면 **그중에서 먼저** 만나요(도감 등록 💎도 그대로 받아요).

### 일일 퀘스트
먹이 3번(80 G) · 관찰 3번(60 G) · 새 식구 2마리(120 G) · 숲 탐색 1번(100 G + 탐색권 1장).

### 전투
- **야생 배틀**: 상대 희귀도를 골라요. 보상 10 / 25 / 70 / 180 / 450 G(등급별), 다이아 확률 4~14%. 쿨다운 8초, 최대 20턴, 능력치·피해 ±15% 편차.
  - **직접 전투**: 보스 타워 직접 전투와 같은 다섯 가지 행동(공격·방어 태세·강력한 일격·회복·계열 기술)을 매 턴 골라요. 상대·능력치·보상·쿨타임은 자동 전투와 똑같고, 야생 개체에게는 보스 패턴이 없어서 강타·웅크리기 예고는 없어요. 일격과 회복을 어느 타이밍에 쓰느냐가 승부를 갈라요(시뮬레이션 기준 같은 전력에서 잘 고르면 승률 약 +12%p, 공격만 고르면 자동 전투와 같아요). 포기하면 패배로 처리돼요.
- **계열 기술**(직접 전투 전용 — 보스 타워·야생 배틀·서바이벌 엘리트): 내 식구의 계열마다 행동이 하나 더 있어요. 약한 공격(피해 50%, 서리는 희귀도에 따라 40~60%)을 하면서 효과를 걸고, 쓰고 나면 일정 턴을 쉬어야 해요. 희귀도가 높을수록 효과가 세요.
  - 🔥 **불길**(쉬는 시간 3턴): 상대에게 화상. 3턴 동안 턴이 끝날 때마다 평범한 공격 한 번의 30~45%(희귀도별) 피해가 들어가요.
  - 🌿 **뿌리 감기**(쉬는 시간 4턴): 상대를 묶어 3턴 동안 공격력이 18~28%(희귀도별) 줄어요. 강타·분노와 곱해져요.
  - ❄️ **빙결**(쉬는 시간 6턴): 이번 턴 상대가 아무것도 하지 못해요. 예고된 보스의 강타 턴에 쓰면 막을 수 있고, 재생·분노도 그 턴에는 일어나지 않아요.
- **리듬 일격**(직접 전투 전용 — 보스 타워·야생 배틀·서바이벌 엘리트·던전): '강력한 일격'을 고르면 **타이밍 바**가 열리고, 좌우로 오가는 마커가 가운데에 올 때 '지금!'(스페이스·엔터·바 터치)을 누르면 정확도(0~1)에 따라 일격 피해가 **−30%~+30%**로 달라져요(가운데 +30%, 중간 0%, 끝 −30%; 무작위로 눌러도 평균은 0%). 서버는 클라이언트가 보낸 정확도를 0~1 범위 안에서만 인정하고(`POST …/duel/act`의 선택 값 `rhythm`), 일격이 아닌 행동에는 적용하지 않아요. 화면의 '🎵 리듬 일격 켬/끔'으로 끄면 예전처럼 일격이 바로 나가요(브라우저에 기억해요).
  - 자동 전투와 투기장에는 없어요. 방어로 모은 힘(×1.5)은 기술 공격에도 실리고, 웅크리기·가시갑옷 같은 보스 패턴도 기술 공격에 똑같이 적용돼요. 기술 상태(쉬는 시간·화상·속박)는 전투와 함께 서버에 저장돼서 새로고침해도 이어져요.
  - 수치는 시뮬레이션으로 맞췄어요: 자동 전투 승률이 50%인 조건에서, 기술 없이 잘 싸우면 약 +15%p인데 기술까지 잘 쓰면 약 +7~10%p 더 올라가요. 아무렇게나 눌러도 손해는 크지 않아요(±3%p). 값을 바꾸면 세 계열이 비슷한 세기인지 다시 확인해야 해요.
- **계열 상성과 전투 환경**(보스 타워·야생 배틀·서바이벌, 자동·직접 전투 공통): 모든 종은 🔥 불꽃 / 🌿 숲 / ❄️ 서리 중 한 계열이에요(불꽃 22종 · 숲 20종 · 서리 18종, 능력치와는 무관한 분류). 불꽃 > 숲 > 서리 > 불꽃 순환 상성이 있어서 이기는 쪽은 공격·방어 **+3%**, 지는 쪽은 **−3%**예요. 여기에 전투 환경이 한 계열을 편들어 그 계열에 공격·방어 **+3%**를 더해요(평범한 땅은 누구도 편들지 않아요). 보정은 HP를 뺀 공격력·방어력에만 곱해지고 소수 둘째 자리까지 유지돼요. 3%가 작아 보여도 접전에서는 승률이 크게 움직여요(같은 전력의 시뮬레이션에서 유리 약 +16%p, 불리 약 −16%p).
  - 야생 배틀의 환경은 전투마다 무작위예요(평범한 땅 40% · 화산 지대·울창한 숲·서리 평원 각 20%). 상대 종도 그때 정해져서 전투를 시작해야 알 수 있어요.
  - 보스 타워의 환경은 층마다 정해져 있어요(1층 평범 → 2층 화산 → 3층 숲 → 4층 서리 → 5층 평범…). 층 정보에서 보스 계열과 환경을 미리 보고, 식구 목록의 ▲유리/▼불리 표시를 보며 고를 수 있어요.
  - 서바이벌은 스테이지마다 적 계열(세 계열 같은 확률)과 환경(야생 배틀과 같은 확률)이 무작위로 정해지고, 그 계열의 종이 적으로 보여요. 환경이 편드는 계열이 내 식구일 수도, 적일 수도 있어서 어느 계열의 식구로 들어가도 평균은 같아요. 직접 전투 모드의 엘리트 전투도 같은 규칙을 받아요(시뮬레이션 기준 평균 도달 스테이지는 그대로예요).
  - 투기장(PvP)에는 적용하지 않아요(레이팅 공정성).
- **전투 레벨**: 종마다 따로, 레벨당 능력치 +8%.
- **훈련**: 쿨다운 30초 / 2분 / 8분, 골드 소모. 극한 훈련은 다이아 4개를 더 쓰고 경험치가 12배.
- **투기장**: 시작 레이팅 1000, 승리 +18 / 패배 −12, 승리 보상 120 G(+8% 확률로 💎1), 쿨다운 10초. 이긴 상대에게는 30분간 재도전 불가. 연승 기록이 업적에 반영돼요.

### 보스 타워
- 50층, 5층마다 보스. 층마다 능력치가 15%씩(복리) 올라가요.
- **보스 패턴 5종**: 웅크리기(3턴마다 받는 피해 40%) · 분노(HP 50% 이하에서 공격 ×1.5) · 강타(4번째 공격 ×2) · 재생(매 턴 HP 3% 회복) · 가시갑옷(준 피해의 15% 반사). 30층 이후는 겹쳐요.
- 하루 **5회**, 전투 사이 **15분** 쿨타임.
- **직접 전투**: 자동 전투 대신 매 턴 행동을 직접 골라요. 도전 횟수·쿨타임·난이도·보상은 자동 전투와 똑같아요. 서버가 전투 상태를 들고 한 턴씩 진행하니 새로고침해도 이어져요. 진행 중에는 다른 보스 전투와 쿨타임 건너뛰기를 할 수 없고, 포기하면 패배로 처리돼요(도전 횟수는 돌아오지 않아요).

| 행동 | 효과 |
|---|---|
| 공격 | 평범한 공격. 계속 이것만 고르면 같은 난수에서 자동 전투와 기록까지 똑같아요 |
| 방어 태세 | 이번 턴 공격을 쉬고 받는 피해 50%, 다음 공격(일격 포함)이 ×1.5 |
| 강력한 일격 | 피해 ×1.5. 쓴 턴에 받는 피해 ×1.4, 쓰고 나면 2턴 쉬어야 해요 |
| 회복 | 이번 턴 공격을 쉬고 최대 HP의 20% 회복, 한 전투에 한 번 |

- 보스의 **강타**(4·8·12…턴)와 **웅크리기**(3·6·9…턴)는 턴 번호로 정해져서 그 턴이 오기 전에 미리 예고해 줘요. 예고를 읽고 방어 태세로 대응하면 유리하고, 아무렇게나 고르면 자동 전투보다 불리할 수 있어요(시뮬레이션 기준 평균 승률: 예고를 읽고 대응 +15%p, 일격만 연타 +5%p, 무작위 −6%p).
- **다이아 편의 기능**: 오늘 도전을 모두 쓰면 추가 도전을 💎20 / 40 / 60(하루 최대 3회)에 살 수 있고, 쿨타임은 남은 3분마다 💎1(꽉 찬 15분이면 💎5)로 건너뛸 수 있어요. 도전이 남아 있을 때는 추가 도전을 팔지 않아요.
- **난이도**: 쉬움 ×1 · 보통 ×1.5 · 어려움 ×2 · 매우 어려움 ×3. 배율은 보스 능력치와 골드·경험치 보상에 곱해져요. 깬 층은 난이도마다 따로 기록되고, 다이아·장비는 난이도별 첫 클리어마다 한 번씩 받아요.
- 보상: 첫 클리어 골드(200 + 120×층, 보스 층 ×3), 보스 층 첫 클리어 시 💎10과 장비 1개. 다시 이기면 골드 25%, 보스 층은 장비 복사본 40%·💎5(2%) 확률.

### 오늘의 퍼즐
- **규칙**: 10×10 판에 바위🪨와 나뭇잎🍃이 있어요. 콩벌레는 방향을 고르면 바위·벽 앞에서 멈출 때까지 굴러가고, 🍃 칸에 닿으면 지나치지 않고 거기서 멈춰요(도착). 제자리로 굴러가는 입력은 이동으로 세지 않아요.
- **하루 10단계**: 단계마다 새로운 판이 나오고 갈수록 어려워져요(목표 최단 수 11 → 12 → 13 → 14 → 16 → 17 → 18 → 20 → 21 → 23수). 앞 단계를 깨야 다음 단계가 열리고, 깬 단계는 다시 풀어 기록을 줄일 수 있어요. 아직 열리지 않은 단계의 판과 최단 수는 내려주지 않아요.
- **모두에게 같은 판**: 날짜와 단계가 시드라서 같은 날 같은 단계는 누구에게나 같은 판이에요(서버가 언제 다시 만들어도 같아요). 무작위 판에서 시작해 바위·시작·도착 칸을 하나씩 옮겨 보며 최단 수를 목표에 맞추는 방식으로 만들고, 풀 수 있는 판만 써요. 퍼즐은 **한국 시간 자정**에 바뀌어요.
- **제출과 검증**: 화면에서 굴러가는 건 미리보기일 뿐이에요. 🍃에 도착하면 이동 기록(`UDLR` 문자열, 최대 80번)을 서버에 보내고, 서버가 시작 칸부터 그대로 다시 굴려서 도착하는지 확인해요. 도착한 뒤 이동이 섞여 있거나 못 도착한 기록, 날짜가 지난 판의 기록, 아직 안 열린 단계의 기록은 거절해요. 시간값은 쓰지 않아서 조작할 구석이 없어요.
- **순위**: 오늘 많이 깬 단계 순이고, 같으면 깬 단계들의 "최단 수 초과분 합"이 적은 순이에요. 성적이 같으면 같은 순위(1, 1, 3…)이고 먼저 달성한 사람이 위에 보여요. 퍼즐 화면에서 상위 20명과 내 순위를 볼 수 있어요.
- **별과 단계 보상**: ★★★ = 최단 수, ★★ = 최단+1~2수, ★ = 그 밖에 클리어. 단계마다 장비 조각 ★ 2개 · ★★ 3개 · ★★★ 4개를 받고, 더 높은 별을 따면 그 단계의 차액만 더 받아요.
- **단계 달성 보너스(하루 한 번씩)**: 3단계 🎟️1 · 5단계 🔩10·💎1 · 8단계 🎟️1·💎1 · 10단계 🎟️1·🔩20·💎2 (🎟️ 탐색권, 🔩 장비 조각). 10단계를 모두 최단으로 깨면 하루 합계 🎟️3 · 🔩70 · 💎4예요.
- **순위 보상(다음 날 받기)**: 어제 한 단계라도 깬 사람은 어제 순위로 1위 💎5 · 2위 💎3 · 3위 💎2 · 4~10위 💎1을 받아요. 퍼즐 화면에서 직접 받으며(어제 것만 받을 수 있어요), 같은 성적이면 모두 같은 순위예요.
- **저장**: 기록은 `puzzle_records`(하루 유저당 한 건, 45일 뒤 자동 삭제), 받은 보상 기록은 게임 상태의 `puzzle`에 보상과 한 번에 저장돼서 중복 지급이 없어요. 하루 한 판이던 시절의 옛 기록은 순위에서 빠져요.

### 콩 달리기
- **게임**: 콩벌레는 화면 왼쪽에 고정이고 땅이 흘러와요. 점프(스페이스·↑·W·화면 탭·화면 아래의 큰 점프 버튼)로 곰팡이를 넘고, 닿으면 끝이에요. 쓰러지지 않고 6분을 버티면 완주로 끝나요. 점프는 땅에서만 할 수 있고, 착지 직전에 누른 점프는 잠깐 기억해 뒀다가 착지하면 바로 뛰어요. 다른 탭으로 가면 자동으로 일시정지해요.
- **콩벌레 선택과 능력**: 가지고 있는 종 중 한 마리를 골라 달려요(고른 종의 그림이 달리고, 마지막에 고른 종을 기억해요). 희귀도마다 능력이 달라요: 일반 = 없음 · 희귀 = 🛡️ 껍질 1겹 · 에픽 = 껍질 1겹 + 🦘 점프력 +6% · 전설 = 껍질 2겹 + 점프력 +6% · 신화 = 껍질 2겹 + 점프력 +6% + 🌀 더블 점프(공중에서 한 번 더, 착지하면 다시 사용). 껍질은 곰팡이에 부딪혀도 한 겹이 깨지고 버티게 해 주고(깨진 뒤 1.5초는 무적), 곰팡이 배치는 어떤 콩벌레든 똑같아요(같은 시드 = 같은 판). 서툰 사람(타이밍 오차 약 67ms) 기준 중앙값이 일반 약 300m, 희귀 약 480m, 에픽 약 590m, 전설 약 680m예요. 종은 시작할 때 서버가 확인하고(가지고 있어야 해요) 희귀도를 판에 적어 두며, 끝날 때 그 희귀도로 서버가 다시 돌려서 점수를 정해요. 순위에는 기록을 세운 콩벌레의 그림과 이름(희귀도 색)이 같이 보여요(좁은 화면에서는 그림만, 이름은 길게 눌러 툴팁으로).
- **난이도**: 속도가 7초마다 올라요(초당 약 3.6m → 약 13m). 곰팡이는 낮은 것과 높은 것이 있고, 너비를 "점프 타이밍 여유(틱)"에서 거꾸로 계산해서 처음에는 여유가 넉넉하다가 갈수록 줄어요(좁은 타이밍에 넓은 곰팡이). 모든 판은 풀 수 있게 만들어져 있어요. 판(곰팡이 배치)은 달릴 때마다 서버가 정하는 시드로 정해져서 매번 달라요.
- **서버 검증**: 게임은 초당 60번(고정 간격) 진행하는 결정적 시뮬레이션이고, 사람이 하는 일은 "몇 번째 틱에 점프했는가"뿐이에요. 달리기를 시작하면 서버가 시드·시작 시각·내보낸 종의 희귀도를 적어 두고, 끝나면 클라이언트가 점프한 틱 목록(최대 4000개)만 보내요. 서버가 같은 시뮬레이션을 처음부터 다시 돌려서 거리를 스스로 계산하니 점수를 직접 보낼 곳이 없어요. 기록이 실제로 흐른 시간(시작 후 지난 시간 + 3초 여유)보다 길면 빨리 감기라서 거절하고, 시작한 지 40분 넘은 판은 무효예요. 한 판은 한 번만 끝낼 수 있고, 새로 시작하면 이전 판은 버려져요.
- **순위**: 그날 가장 멀리 달린 거리(미터)가 기록이에요. 같은 거리는 같은 순위(1, 1, 3…)이고 먼저 달성한 사람이 위에 보여요. 한국 시간 자정에 새로 시작해요.
- **거리 보너스(하루 한 번씩)**: 오늘 최고 기록이 150m 🔩5 · 400m 🔩10 · 800m 🎟️1·🔩10 · 1,500m 🔩15·💎1 · 2,500m 🎟️1·💎1에 닿을 때마다 받아요(하루 합계 🎟️2 · 🔩40 · 💎2). 나눠서 닿아도 합계는 같아요.
- **한계**: 판이 결정적이라 시드를 알면 완벽하게 뛰는 프로그램을 만들 수는 있어요. 기록이 실제 시간만큼 걸려야 하고 보너스에 하루 상한이 있어서 피해를 줄였을 뿐 막을 수는 없어요.
- **저장**: 기록은 `runner_records`(하루 유저당 한 건, 45일 뒤 자동 삭제), 달리는 판과 받은 보너스 기록은 게임 상태의 `runner`에 보상과 한 번에 저장돼요.

### 서바이벌
- 하루 **3회** 입장(입장할 때 차감, 쓰러지거나 그만둬도 돌려주지 않아요). 식구 한 마리를 골라 들어가면 그 식구의 레벨·장비가 반영된 능력치를 **입장할 때 한 번 굴려 고정**해요. 런 도중 레벨이나 장비를 바꿔도 이번 런에는 영향이 없어요.
- 1스테이지 적은 45 / 9 / 4(HP / 공격 / 방어)이고 스테이지마다 **8%씩(복리)** 강해져요. **5스테이지마다 엘리트**가 나오고 보스 패턴을 써요(30스테이지부터 두 개가 겹쳐요). 100스테이지를 모두 깨면 완주예요.
- 스테이지를 깰 때마다 최대 HP의 **15%** 를 회복하고, HP는 다음 스테이지로 이어져요. 쓰러지면 그 구간에서 멈춰요.
- **엘리트 직접 전투 모드**: 입장할 때 "🎮 엘리트 직접 전투"를 고르면 일반 스테이지는 자동으로 깨고, 5스테이지마다 나오는 엘리트와는 매 턴 행동(공격·방어 태세·강력한 일격·회복)을 직접 골라 싸워요(스테이지 수백 번을 일일이 고르면 지루해서 엘리트만 직접 해요). 보상·회복·버프 선택·부활 규칙은 자동 진행과 같고, 회복은 엘리트와 엘리트 사이(한 구간)에 한 번만 써요. 시뮬레이션 기준 평균 도달 스테이지는 자동 진행과 거의 같아요(공격만 고르면 같고, 예고를 읽고 대응하면 약 +1%).
- **부활과 추가 입장(💎)**: 쓰러진 런은 💎30 / 60 / 120(한 번의 도전에 최대 3번)으로 부활해서 같은 스테이지부터 이어갈 수 있어요(최대 HP의 60%로 되살아나요). 부활하지 않고 마치거나 새로 입장하면 그 런은 끝나요. 오늘 입장 3회를 모두 쓰면 추가 입장을 💎30 / 60 / 90(하루 최대 3회)에 살 수 있어요.
- 엘리트를 쓰러뜨리면 서버가 버프 후보 **3개**를 보여주고 하나를 골라야 다음 구간(5스테이지)이 진행돼요. 같은 버프는 중첩돼요.

| 버프 | 효과 |
|---|---|
| 날카로운 이빨 | 공격력 +25% |
| 단단한 껍질 | 방어력 +35% |
| 튼튼한 체력 | 최대 HP +25% (늘어난 만큼 바로 회복) |
| 숲의 휴식 | HP를 최대의 50% 회복 |
| 빠른 회복 | 스테이지를 깰 때마다 회복량 +5%p |

- 보상은 스테이지를 깰 때마다 바로 받아요: 골드 `15 + 5×스테이지`, 그 식구의 전투 경험치 `6 + 2×스테이지`. 이전 최고 기록을 넘어 새로 지나간 5스테이지 단위마다 💎2, 10 / 20 / 30 / 40스테이지에 처음 도달하면 희귀 / 에픽 / 전설 / 신화 장비를 1개 받아요.
- 진행 중인 런은 서버에 저장돼요. 새로고침하거나 다른 기기로 들어와도 같은 선택지가 그대로 보여요.

### 부스트 상점
- 수익 부스트(자동 수익 ×2) · 번식 촉진(번식 진행 ×2) · 전투 경험치 부스트(야생 배틀·훈련·보스·서바이벌 경험치 ×2). 1시간짜리와 4시간짜리(10% 저렴)가 있고, 같은 부스트를 이어서 사면 시간이 더해져요(최대 24시간).
- 1시간 가격은 내 사육장이 한 시간에 버는 최대 수익(쾌적한 환경 기준)에 비례해요. 번식 촉진·경험치 부스트는 그 금액 그대로, 수익 부스트는 15% 싸요. 아무리 작아도 1시간에 1,000 G예요.
- 부스트는 시작·종료 시각으로 저장되고, 시간이 흐르는 계산은 처리하는 구간과 겹친 부분에만 배율을 적용해요(구매 이전 시간은 부풀려지지 않아요).

### 장비
- 뽑기 1회 💎40, 10연차 💎360(마지막에 희귀 이상 보장). 등급 확률 55 / 28 / 12 / 4 / 1%, **50회 연속** 전설 이상이 안 나오면 50번째는 확정.
- 종류: 무기(공격) · 방어구(방어) · 장신구(HP), 총 30종. 효과 = 등급별 기본값(2 / 3 / 5 / 7 / 10%) × (1 + 0.15 × (레벨 − 1) + 0.05 × 각성 횟수).
- 레벨업은 같은 장비를 **현재 레벨 수치만큼** 모아야 해요(수동). 최대 레벨(기본 5)에서 골드로 **각성**(성공 70%, 실패할 때마다 +5%p)하면 최대 레벨 +3, 효과 +5%.
- 슬롯은 기본 3칸, 4번째 💎300, 5번째 💎666.
- **세트 효과**: 30종은 테마별 10개 세트(희귀도마다 2세트)로 묶여요. 한 세트는 무기·방어구·장신구 하나씩이고, 같은 세트를 **2개** 장착하면 공격력·방어력·HP가 모두 일반 +1% / 희귀 +1.5% / 에픽 +2% / 전설 +3% / 신화 +4%, **3개**면 +3% / +4.5% / +6% / +9% / +12%예요(3개 효과가 2개 효과를 대신해요). 5칸이면 한 세트 3개 + 다른 세트 2개를 함께 쓸 수 있어요.
- **장비 조각**: 쓰지 않는 중복(복사본)을 분해하면 조각을 얻어요(복사본 1개당 일반 4 / 희귀 10 / 에픽 25 / 전설 60 / 신화 150). 레벨업에 모자란 중복은 조각과 골드로 메꿀 수 있어요(모자란 1개당 조각 6 / 15 / 38 / 90 / 225 + 골드 100 / 300 / 1,000 / 3,000 / 10,000). 이미 모은 중복을 먼저 쓰고, 분해로 얻는 양보다 1.5배가 들어서 같은 장비를 직접 모으는 쪽이 늘 이득이에요. 장착 중인 장비의 중복은 일괄 분해에서 빠져요.

### 성장과 보상
- 계정 레벨업마다 다이아 3개. 새 종을 처음 만나면 다이아(일반 1 ~ 신화 15).
- 닉네임 변경 💎200, 종 별명은 무료.
- 친구 선물: 하루 한 번 서로에게 💎2.

## API 개요

모든 주소는 `/api` 아래에 있어요. 로그인(`auth/google*`)과 종·업그레이드·퀘스트·업적 목록(`species`, `upgrades`, `quests`, `achievements`)은 로그인 없이 열려 있고, 나머지는 `Authorization: Bearer <JWT>`가 필요해요. 관리자 전용은 `admin/...`이고 관리자 계정만 접근할 수 있어요.

| 영역 | 경로 |
|---|---|
| 인증 | `GET auth/google` · `GET auth/google/callback` · `GET auth/me` · `POST auth/profile-message` |

## 개발 가이드

### 서버와 프론트에 같은 계산이 두 벌 있어요
미리보기(비용·스탯·진행도)를 화면에서 바로 보여주려고 일부 상수와 함수가 양쪽에 있어요. **값을 바꿀 때는 두 곳을 함께** 고쳐야 해요.

| 백엔드 | 프론트엔드 |
|---|---|
| `game-state/game-engine.ts` | `frontend/src/utils/gameCalc.ts` |
| `game-state/puzzle-engine.ts`(굴리기 규칙) | `frontend/src/utils/puzzle.ts` |
| `game-state/runner-engine.ts`(콩 달리기 시뮬레이션) | `frontend/src/utils/runner.ts` (**한 틱도 어긋나면 안 돼요**) |
| `decor/decor.data.ts`의 `getDecorBreedBonusPercent`·`normalizeDecorProps`·`summarizeDecor`(꾸미기 번식 보너스·업적 요약, 장식 목록은 `GET /decor`) | `frontend/src/utils/decor.ts` |

예: 탐색 비용(`EXPLORE_COST_*`), 장비 효과, 전투 스탯, 보스 난이도 진행도 필드, 업적 진행도 계산 등. 보스 층의 능력치·보상과 서바이벌의 규칙·버프 목록은 서버가 `GET /boss`, `GET /survival`로 내려줘서 프론트에 계산식이 없어요.

### 데이터의 기준
- 종·업그레이드·퀘스트·업적은 **시드 파일이 기준**이에요. 서버가 시작될 때마다 DB에 덮어써요(upsert). 종의 분양가와 분당 수익은 `species.seed-data.ts`의 `RARITIES` 한 곳에서 정해요. 종의 계열(불꽃·숲·서리)은 `species.family.ts`의 매핑이 기준이고 시드에 같이 쓰여요.
- 장식 카탈로그(`decor/decor.data.ts`)와 장비 카탈로그(`equipment/equipment.data.ts`)와 보스 층 정보(`getBossFloor`), 서바이벌 적 공식(`getSurvivalEnemy`)은 DB에 저장하지 않고 **코드가 기준**이에요.
- 새 업적 통계를 추가하려면 `AchievementStatKey`(백엔드 스키마), `game-engine.ts`의 `getAchievementProgress`, 프론트 `types.ts`·`gameCalc.ts`, 업적 아이콘(`AchievementsView.tsx`)을 함께 고쳐요.

### 업데이트 내역
새 기능·밸런스·수정을 반영할 때 `frontend/src/data/CHANGELOG.md`에 **날짜 → 카테고리(✨ 신규 기능 / ⚖️ 밸런스 / 🐛 수정 / 🛠️ 기타) → 항목** 순서로 적어요. 같은 파일을 게임 안 사이드바 '업데이트 내역' 화면이 그대로 읽어서(형식은 `utils/changelog.ts` 참고) 프론트를 다시 빌드하면 반영돼요. 🛠️ 기타와 커밋 해시는 게임 화면에서 숨겨요. 새 날짜가 생기면 아직 못 본 유저의 사이드바에 NEW가 떠요.

### 홍보 팝업
접속하면 한 번 뜨는 홍보 팝업(새 콩벌레 소개 등)은 `frontend/src/utils/promoPopup.ts`의 `PROMO_POPUPS`에 항목(`id`, 끝나는 시각 `endsAt`, 제목·문구, 보여줄 `speciesIds`)을 추가하면 돼요. '닫기'는 이번 접속에서만, '24시간 동안 닫기'는 이 브라우저의 그 계정에서 24시간 동안 닫아요(`id`가 다르면 따로 닫혀요). `endsAt`이 지나면 저절로 안 떠요.

### Mongoose 주의점
- `@Prop({ type: Types.ObjectId })`로 선언한 필드는 스키마상 `Mixed`예요. 쿼리할 때 문자열 id를 그대로 쓰면 매칭되지 않으니 **항상 `new Types.ObjectId(id)`로 변환**해요.
- `string | null` 같은 유니온 타입은 `@Prop({ type: String })`처럼 타입을 명시해야 해요(안 하면 서버가 시작 중에 죽어요).
- `.lean()`은 스키마 기본값을 채우지 않아요. 새 필드를 추가하면 예전 문서는 값이 없을 수 있으니 `?? 기본값`으로 읽어요.
- 배열은 원소를 직접 대입하지 말고 배열 전체를 다시 대입해야 변경이 저장돼요.

### 배포 전 점검 (권장)
`npm run build` 후 다른 포트에서 먼저 띄워서(`PORT=3099 node dist/main.js`) 정상 시작하는지 확인하고 나서 운영 프로세스를 재시작하면 잘못된 배포로 서비스가 죽는 것을 막을 수 있어요.
