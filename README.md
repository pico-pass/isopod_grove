# 🪲 ISOPOD GROVE (콩벌레 숲)

콩벌레(등각류)를 키우고 모으고 싸우게 하는 **브라우저 방치형 육성 게임**이에요.
사육장을 가꿔 식구를 늘리고, 숲을 탐색해 새로운 종을 만나고, 전투·장비·보스 타워로 성장하고, 친구와 채팅하고 우편으로 보상을 받아요.

- 서비스 주소: <https://isopogrove.click>
- 로그인: Google 계정
- 업데이트 내역: [CHANGELOG.md](frontend/src/data/CHANGELOG.md) (날짜별·카테고리별, 게임 안 사이드바 '업데이트 내역'에서도 볼 수 있어요)

## 주요 기능

### 사육과 수집
- **사육장 관리**: 사육장마다 먹이·습도·온도를 돌봐요. 환경이 쾌적하면 식구가 번식하고 자동 수익이 나와요(자리를 비워도 최대 8시간까지 진행돼요. 단, **전설·신화 번식은 자리를 비운 시간 전부**가 반영돼요 — 서버가 잰 실제 경과 시간만 인정하고, 자동 먹이 공급기·자동 분무기로 환경이 유지될 때 진행돼요).
- **등각류 도감**: 55종(일반 11 · 희귀 6 · 에픽 16 · 전설 14 · 신화 8)을 모아요. 새 종을 만나면 다이아를 받아요.
- **숲 탐색**: 탐색할 때마다 같은 종 2마리를 만나요. 등급 확률이 낮고 비용이 계속 올라가요.
- **원정**: 숲 탐색 비용의 수십~수백 배를 내고 에픽 이상(대원정은 전설 이상)을 확정으로 만나요. 신화는 천장이 있어요.
- **분양 마켓**: 시세가 5분마다 ±25% 범위에서 오르내려요. 실수로 팔지 않도록 종을 잠글 수 있어요.
- **사육장 이름**: 사육장마다 이름을 무료로 바꿀 수 있어요(최대 20자). 다른 유저가 사육장을 구경할 때도 이 이름이 보여요.
- **사육장 꾸미기**: 골드로 배경·소품 장식 25종을 사서 사육장마다 배경 1개와 소품 4칸을 꾸며요. 계열(불꽃·숲·서리) 장식은 그 사육장에 사는 같은 계열 종의 번식을 빠르게 해요.
- **업그레이드**: 사육장 확장, 바닥재(수익), 번식 쉼터(번식 시간), 자동 먹이 공급기, 자동 분무기.
- **부스트 상점**: 골드를 내고 일정 시간 동안 수익·번식·전투 경험치를 2배로 만들어요.
- **종 별명**: 내 화면에서만 보이는 별명을 지어줄 수 있어요.

### 전투와 성장
- **야생 배틀**: 상대 희귀도를 직접 골라 턴제로 싸워요. 종마다 전투 레벨이 따로 올라요. 자동 전투 외에 매 턴 행동을 고르는 **직접 전투**도 있어요(보스 타워·서바이벌 엘리트도 마찬가지).
- **전투 훈련**: 강도 3단계(가벼움·보통·강도 높음)와 극한 훈련(다이아 소모, 경험치 ×12).
- **투기장(PvP)**: 다른 유저가 정해 둔 방어 식구와 비동기로 싸우고 레이팅을 올려요. 이긴 상대에게는 30분 동안 재도전할 수 없어요.
- **보스 타워**: 50층, 5층마다 패턴 보스가 있어요. 난이도 4단계(쉬움·보통·어려움·매우 어려움)가 있고 깬 층은 난이도별로 따로 기록돼요. 자동 전투 외에 매 턴 행동을 고르는 **직접 전투**도 있어요.
- **서바이벌(무한 전투)**: 식구 한 마리로 HP를 이어 가며 스테이지를 끝없이 깨요. 5스테이지마다 엘리트가 나오고, 엘리트를 쓰러뜨릴 때마다 버프를 3개 중 하나 골라요.
- **오늘의 퍼즐 "굴러라 콩벌레"**: 하루 10단계, 단계마다 새로운 10×10 슬라이드 퍼즐이 나오고 갈수록 어려워져요(모두에게 같은 순서). 방향을 고르면 바위나 벽에 부딪힐 때까지 굴러가고 🍃에 닿으면 도착이에요. 많이 깰수록·적은 수로 깰수록 높은 순위이고, 별점·단계 보너스·순위 보상이 있어요. 실시간이 아니라 언제든 천천히 풀 수 있어요.
- **콩 달리기 "달려라 콩벌레"**: 가지고 있는 콩벌레 한 마리를 골라(그 종의 그림으로 달려요) 달리면서 곰팡이🦠를 점프로 피하는 러너 게임이에요. 희귀할수록 능력(껍질·점프력·더블 점프)이 많아요. 스페이스·↑·화면 탭·점프 버튼으로 점프하고, 갈수록 빨라지고 곰팡이가 넓어져요. 오늘 가장 멀리 달린 순위와 거리 보너스가 있어요. 점수는 서버가 점프 기록을 다시 돌려서 정해요.
- **장비**: 다이아 뽑기(천장 있음), 레벨업(중복 획득 개수 필요), 각성, 슬롯 확장, 중복 분해·조각 레벨업, 세트 효과. 야생 배틀·투기장·보스 타워·서바이벌에 모두 적용돼요.
- **업적 84종**과 **일일 퀘스트 4종**, **랭킹**(숲 레벨 · 분당 수익 · 투기장 레이팅 · 보스 타워 · 서바이벌, 그리고 퍼즐·콩 달리기 화면의 오늘의 순위). 모든 랭킹에서 **보기: 20명 / 50명 / 100명**을 고를 수 있고(마지막으로 고른 값을 기억해요), 내 순위가 보여주는 인원 밖이어도 따로 보여줘요.

### 소셜
- **사육장 방문**: 다른 숲지기의 사육장(장식·식구)을 구경하고 사육장마다 ❤️ 좋아요를 눌러요(선물은 없어요). 인기 사육장 순위와 랜덤 방문이 있고, 내 사육장은 설정으로 비공개로 바꿀 수 있어요.
- **친구**: 요청·수락·삭제, 하루 한 번 서로에게 다이아 선물(시스템이 지급하고 선물한 사람은 잃는 게 없어요), 접속 중 표시.
- **친구 채팅**: 친구끼리 1:1 채팅, 읽음 표시, 내 메시지 삭제, 메시지 신고.
- **공동 채팅방**: 자유방·질문방·문의방 3개 채널과 현재 접속자 목록.
- **프로필**: 닉네임(다이아로 변경)과 프로필 메시지, 다른 유저 프로필 보기.

### 우편함과 알림
- **우편함**: 운영자가 보낸 메시지와 자원(골드·다이아·탐색권)을 받아요.
- **웹 푸시 알림**: 친구 메시지·우편이 오면 브라우저로 알려줘요. 알림 종류별 켜기·끄기를 지원해요.

### 관리자 (서버 관리 페이지)
- 서버·경제 현황, **우편 발송**(전체/선택 유저, 프리셋, 발송 내역), **채팅 신고 처리**와 **채팅 정지**(N일, 해제).
- 관리자 지정은 `users` 컬렉션에서 해당 유저의 `isAdmin`을 `true`로 바꿔요(화면에서 바꾸는 기능은 없어요).

## 시작하기 (로컬 개발)

### 준비물
- Node.js 22 이상 (운영 서버와 Docker 이미지는 24)
- MongoDB 접속 주소 (로컬 MongoDB 또는 Atlas)
- Google OAuth 클라이언트 (Google Cloud Console → 사용자 인증 정보)
  - 승인된 리디렉션 URI: `http://localhost:3000/api/auth/google/callback`

### 백엔드

```bash
cd backend
cp .env.example .env      # 값을 채운다(아래 환경 변수 표 참고)
npm install
npm run start:dev         # http://localhost:3000/api  (파일을 바꾸면 자동으로 다시 시작)
```

서버가 시작될 때 종·업그레이드·퀘스트·업적 데이터가 DB에 자동으로 반영돼요(시딩).

### 프론트엔드

```bash
cd frontend
cp .env.example .env      # VITE_API_URL=http://localhost:3000/api
npm install
npm run dev               # http://localhost:5173
```

로그인하면 백엔드가 `FRONTEND_URL/auth/callback?token=...`으로 돌려보내고, 프론트가 토큰을 저장해요(JWT 유효기간 7일).

### 자주 쓰는 명령

| 위치 | 명령 | 설명 |
|---|---|---|
| backend | `npm run build` | 컴파일(`dist/`) |
| backend | `npm run start:prod` | 컴파일 결과로 실행 |
| backend | `npm run lint` / `npm test` | 린트 / 테스트(지금은 기본 예제 테스트만 있어요) |
| frontend | `npm run build` | 타입 검사 + 프로덕션 빌드(`dist/`) |
| frontend | `npm run lint` | 린트 |

## 환경 변수

### 백엔드 (`backend/.env`, `backend/.env.example` 참고)

| 변수 | 설명 |
|---|---|
| `PORT` | 서버 포트(기본 3000) |
| `MONGODB_URI` | MongoDB 접속 주소 |
| `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` | Google OAuth 클라이언트 |
| `GOOGLE_CALLBACK_URL` | 로그인 콜백 주소. 예: `http://localhost:3000/api/auth/google/callback` |
| `FRONTEND_URL` | 로그인 후 돌아갈 프론트엔드 주소. 예: `http://localhost:5173` |
| `JWT_SECRET` | JWT 서명 키(`openssl rand -hex 32` 등으로 생성) |
| `VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` / `VAPID_SUBJECT` | 웹 푸시용 키. 비워 두면 푸시만 꺼져요. 생성: `npx web-push generate-vapid-keys` |

> `.env`는 git에 올라가지 않아요. 비공개 키와 비밀번호를 저장소에 커밋하지 마세요.

### 프론트엔드 (`frontend/.env`)

| 변수 | 설명 |
|---|---|
| `VITE_API_URL` | 백엔드 API 주소. 빌드할 때 코드에 박혀요. 예: `http://localhost:3000/api` 또는 같은 도메인이면 `/api` |

## Docker로 실행

백엔드·프론트엔드 각각 `Dockerfile`이 있고, `docker-compose.yml`로 함께 실행해요.

```bash
cp backend/.env.example backend/.env    # 값을 채운다. MongoDB는 외부(Atlas 등)를 가리켜요
docker compose up -d --build
# 접속: http://localhost:8080   (포트 변경: WEB_PORT=80 docker compose up -d)
```

- 프론트 컨테이너(nginx, 8080 포트)가 정적 파일을 서비스하고 `/api`를 백엔드 컨테이너로 프록시해요. 같은 도메인이라 CORS 설정이 필요 없어요.
- compose로 띄울 때는 `backend/.env`의 `FRONTEND_URL`을 `http://localhost:8080`으로, `GOOGLE_CALLBACK_URL`을 `http://localhost:8080/api/auth/google/callback`으로 바꾸고 Google 콘솔에도 같은 콜백 주소를 등록해야 로그인돼요.
- `VITE_API_URL`은 빌드 인자예요(기본 `/api`). 백엔드를 다른 주소로 따로 서비스하면 `--build-arg VITE_API_URL=...`로 넣어요.
- `.env`는 이미지에 들어가지 않고 실행할 때 주입돼요.

## 운영 배포

현재 운영 구성(참고용): 한 서버에서 **nginx**가 `frontend/dist`를 정적 서비스하고 `/api/`를 NestJS(**pm2**, 포트 3000)로 프록시해요.

```bash
# 백엔드
cd backend && npm ci && npm run build
pm2 restart backend            # 처음이면: pm2 start dist/main.js --name backend

# 프론트엔드
cd frontend && npm ci && npm run build   # VITE_API_URL=https://<도메인>/api
```

- **HTTPS가 필요해요**: Google 로그인 콜백과 웹 푸시(서비스 워커)는 HTTPS에서 동작해요.
- nginx는 `sw.js`와 `index.html`을 캐시하지 않게 해야 새 배포와 푸시 알림이 바로 반영돼요(Docker용 `frontend/nginx/default.conf.template` 참고).
- **단일 서버 프로세스를 전제로 해요**: 접속 정보, 채팅 도배 방지, 보스·투기장·서바이벌 동시 요청 잠금이 메모리에 있어요. 서버를 여러 대로 늘리려면 이 상태를 Redis 같은 공유 저장소로 옮겨야 해요.
- 일일 초기화(일일 퀘스트, 무료 탐색권 충전 등)는 **서버의 로컬 시간** 기준이에요.

### 사육
- 환경이 **쾌적**(먹이 25 이상, 습도 65~85%, 온도 20~26°C)하면 수익 100%, 아니면 40%예요. 번식은 먹이 15 이상·습도 50~92%·온도 18~28°C에서만 돼요.
- 돌봄: 먹이 +30, 분무(습도 78%), 온도 조절(24°C). 같은 동작은 10초마다 한 번.
- 사육장은 최대 10개, 이름은 20자 이하로 무료 변경(같은 이름·빈 이름·제어 문자는 거절), 다음 사육장 비용은 `8,750 × 2.5^(보유 수 − 1)` G. 수용량은 기본 20마리에 확장 단계마다 +20.
- 분양은 사육장에 있는 만큼 얼마든지 할 수 있어요(번식은 한 사육장에 같은 종이 2마리 이상 있어야 해요). 이 분양으로 **계정 전체에서 그 종이 0마리가 되면** 확인이 필요해요(전설·신화는 종 이름을 직접 입력). 서버도 확인 값이 없으면 거절해요.
- **종 잠금**: 마켓 카드의 🔓/🔒로 종을 잠그면 어느 사육장에서도 분양할 수 없어요(이사·번식·전투는 그대로). 도감에 있는 종만 잠글 수 있어요.
- 업그레이드: 공간 확장(5단계) · 바닥재(수익 +25%/단계, 5단계) · 번식 쉼터(번식 시간 −12%/단계, 5단계) · 자동 먹이 공급기 · 자동 분무기.

### 사육장 꾸미기와 방문
- 장식은 **골드로 한 번 사면 계정에 영구히 남고**, 어느 사육장에든 무료로 옮겨 놓을 수 있어요. 배경(사육장마다 1개)과 소품(사육장마다 4칸, 같은 소품을 한 사육장에 두 개 놓을 수는 없어요)이 있어요.
- 장식은 계열(불꽃·숲·서리) 장식과 꾸미기 전용으로 나뉘어요. 계열 장식은 그 사육장에서 **같은 계열 종의 번식 진행**을 빠르게 해요(배경 +2/4/6%, 소품 +1/2/3%, 일반/희귀/에픽). 한 사육장·한 계열의 최대는 +12%예요. 번식 촉진 부스트와는 곱해지고, 8시간을 넘는 자리 비움(전설·신화 번식)에도 적용돼요.
- 가격(계열 장식): 배경 10,000 / 100,000 / 2,000,000 G, 소품 4,000 / 40,000 / 600,000 G. 꾸미기 전용은 절반이에요.
- **방문**: 누구나 `GET visit/:userId`로 공개 사육장의 장식·식구(종·마릿수)를 볼 수 있어요. 골드·다이아 같은 자원과 종 별명은 보이지 않아요. 설정에서 비공개로 하면 나만 볼 수 있고, 인기 사육장 순위에서도 빠져요.
- **좋아요**: 사육장마다 사람당 한 번(다시 누르면 취소)이에요. 내 사육장에는 누를 수 없어요. 받은 좋아요는 `terrarium_likes` 컬렉션을 세서 구하고, 보상은 없어요. 순위는 모든 사육장의 합계예요.

### 숲 탐색
- 첫 탐색 **500 G**, 탐색할 때마다 다음 비용이 **25 G씩 올라가요**(매일 초기화되지 않아요). 탐색권으로 한 탐색도 횟수에 포함돼요.
- **탐색권**은 골드로 살 수 없어요. 하루 1장 무료 충전(최대 5장까지), 일일 퀘스트·업적·우편 보상으로 얻어요. 탐색권을 쓰면 골드가 들지 않아요.

### 원정
- 가격은 **지금의 숲 탐색 비용(500 G + 25 G × 탐색 횟수)에 정확히 배수만큼 곱한 값**이에요. 탐색권으로는 갈 수 없고, 원정도 숲 탐색 한 번으로 세어져서 다음 탐색 비용이 올라가요. 한 번에 같은 종 2마리를 데려와요.

| 단계 | 가격 | 확률 |
|---|---|---|
| 원정 | 지금의 숲 탐색 비용 ×40 | 에픽 80% · 전설 17% · 신화 3% |
| 대원정 | 지금의 숲 탐색 비용 ×150 | 전설 80% · 신화 20% |

- **신화 천장**: 신화를 못 만난 채 다녀온 횟수가 29번이 되면 30번째 원정은 단계와 상관없이 신화가 확정이고, 신화가 나오면 천장은 처음으로 돌아가요.
- 뽑힌 등급에 아직 도감에 없는 종이 남아 있으면 **그중에서 먼저** 만나요(도감 등록 💎도 그대로 받아요).

### 일일 퀘스트
먹이 3번(80 G) · 관찰 3번(60 G) · 새 식구 2마리(120 G) · 숲 탐색 1번(100 G + 탐색권 1장).

### 전투
- **야생 배틀**: 상대 희귀도를 골라요. 보상 10 / 25 / 70 / 180 / 450 G(등급별), 다이아 확률 4~14%. 쿨다운 8초, 최대 20턴, 능력치·피해 ±15% 편차.
  - **직접 전투**: 보스 타워 직접 전투와 같은 네 가지 행동(공격·방어 태세·강력한 일격·회복)을 매 턴 골라요. 상대·능력치·보상·쿨타임은 자동 전투와 똑같고, 야생 개체에게는 보스 패턴이 없어서 강타·웅크리기 예고는 없어요. 일격과 회복을 어느 타이밍에 쓰느냐가 승부를 갈라요(시뮬레이션 기준 같은 전력에서 잘 고르면 승률 약 +12%p, 공격만 고르면 자동 전투와 같아요). 포기하면 패배로 처리돼요.
- **계열 상성과 전투 환경**(보스 타워·야생 배틀·서바이벌, 자동·직접 전투 공통): 모든 종은 🔥 불꽃 / 🌿 숲 / ❄️ 서리 중 한 계열이에요(불꽃 20종 · 숲 19종 · 서리 16종, 능력치와는 무관한 분류). 불꽃 > 숲 > 서리 > 불꽃 순환 상성이 있어서 이기는 쪽은 공격·방어 **+3%**, 지는 쪽은 **−3%**예요. 여기에 전투 환경이 한 계열을 편들어 그 계열에 공격·방어 **+3%**를 더해요(평범한 땅은 누구도 편들지 않아요). 보정은 HP를 뺀 공격력·방어력에만 곱해지고 소수 둘째 자리까지 유지돼요. 3%가 작아 보여도 접전에서는 승률이 크게 움직여요(같은 전력의 시뮬레이션에서 유리 약 +16%p, 불리 약 −16%p).
  - 야생 배틀의 환경은 전투마다 무작위예요(평범한 땅 40% · 화산 지대·울창한 숲·서리 평원 각 20%). 상대 종도 그때 정해져서 전투를 시작해야 알 수 있어요.
  - 보스 타워의 환경은 층마다 정해져 있어요(1층 평범 → 2층 화산 → 3층 숲 → 4층 서리 → 5층 평범…). 층 정보에서 보스 계열과 환경을 미리 보고, 식구 목록의 ▲유리/▼불리 표시를 보며 고를 수 있어요.
  - 서바이벌은 스테이지마다 적 계열(세 계열 같은 확률)과 환경(야생 배틀과 같은 확률)이 무작위로 정해지고, 그 계열의 종이 적으로 보여요. 환경이 편드는 계열이 내 식구일 수도, 적일 수도 있어서 어느 계열의 식구로 들어가도 평균은 같아요. 직접 전투 모드의 엘리트 전투도 같은 규칙을 받아요(시뮬레이션 기준 평균 도달 스테이지는 그대로예요).
  - 투기장(PvP)에는 적용하지 않아요(레이팅 공정성).
- **전투 레벨**: 종마다 따로, 레벨당 능력치 +8%.
- **훈련**: 쿨다운 30초 / 2분 / 8분, 골드 소모. 극한 훈련은 다이아 4개를 더 쓰고 경험치가 12배.
- **투기장**: 시작 레이팅 1000, 승리 +18 / 패배 −12, 승리 보상 120 G(+8% 확률로 💎1), 쿨다운 10초. 이긴 상대에게는 30분간 재도전 불가. 연승 기록이 업적에 반영돼요.

### 보스 타워
- 50층, 5층마다 보스. 층마다 능력치가 15%씩(복리) 올라가요.
- **보스 패턴 5종**: 웅크리기(3턴마다 받는 피해 40%) · 분노(HP 50% 이하에서 공격 ×1.5) · 강타(4번째 공격 ×2) · 재생(매 턴 HP 3% 회복) · 가시갑옷(준 피해의 15% 반사). 30층 이후는 겹쳐요.
- 하루 **5회**, 전투 사이 **15분** 쿨타임.
- **직접 전투**: 자동 전투 대신 매 턴 행동을 직접 골라요. 도전 횟수·쿨타임·난이도·보상은 자동 전투와 똑같아요. 서버가 전투 상태를 들고 한 턴씩 진행하니 새로고침해도 이어져요. 진행 중에는 다른 보스 전투와 쿨타임 건너뛰기를 할 수 없고, 포기하면 패배로 처리돼요(도전 횟수는 돌아오지 않아요).

| 행동 | 효과 |
|---|---|
| 공격 | 평범한 공격. 계속 이것만 고르면 같은 난수에서 자동 전투와 기록까지 똑같아요 |
| 방어 태세 | 이번 턴 공격을 쉬고 받는 피해 50%, 다음 공격(일격 포함)이 ×1.5 |
| 강력한 일격 | 피해 ×1.5. 쓴 턴에 받는 피해 ×1.4, 쓰고 나면 2턴 쉬어야 해요 |
| 회복 | 이번 턴 공격을 쉬고 최대 HP의 20% 회복, 한 전투에 한 번 |

- 보스의 **강타**(4·8·12…턴)와 **웅크리기**(3·6·9…턴)는 턴 번호로 정해져서 그 턴이 오기 전에 미리 예고해 줘요. 예고를 읽고 방어 태세로 대응하면 유리하고, 아무렇게나 고르면 자동 전투보다 불리할 수 있어요(시뮬레이션 기준 평균 승률: 예고를 읽고 대응 +15%p, 일격만 연타 +5%p, 무작위 −6%p).
- **다이아 편의 기능**: 오늘 도전을 모두 쓰면 추가 도전을 💎20 / 40 / 60(하루 최대 3회)에 살 수 있고, 쿨타임은 남은 3분마다 💎1(꽉 찬 15분이면 💎5)로 건너뛸 수 있어요. 도전이 남아 있을 때는 추가 도전을 팔지 않아요.
- **난이도**: 쉬움 ×1 · 보통 ×1.5 · 어려움 ×2 · 매우 어려움 ×3. 배율은 보스 능력치와 골드·경험치 보상에 곱해져요. 깬 층은 난이도마다 따로 기록되고, 다이아·장비는 난이도별 첫 클리어마다 한 번씩 받아요.
- 보상: 첫 클리어 골드(200 + 120×층, 보스 층 ×3), 보스 층 첫 클리어 시 💎10과 장비 1개. 다시 이기면 골드 25%, 보스 층은 장비 복사본 40%·💎5(2%) 확률.

### 오늘의 퍼즐
- **규칙**: 10×10 판에 바위🪨와 나뭇잎🍃이 있어요. 콩벌레는 방향을 고르면 바위·벽 앞에서 멈출 때까지 굴러가고, 🍃 칸에 닿으면 지나치지 않고 거기서 멈춰요(도착). 제자리로 굴러가는 입력은 이동으로 세지 않아요.
- **하루 10단계**: 단계마다 새로운 판이 나오고 갈수록 어려워져요(목표 최단 수 11 → 12 → 13 → 14 → 16 → 17 → 18 → 20 → 21 → 23수). 앞 단계를 깨야 다음 단계가 열리고, 깬 단계는 다시 풀어 기록을 줄일 수 있어요. 아직 열리지 않은 단계의 판과 최단 수는 내려주지 않아요.
- **모두에게 같은 판**: 날짜와 단계가 시드라서 같은 날 같은 단계는 누구에게나 같은 판이에요(서버가 언제 다시 만들어도 같아요). 무작위 판에서 시작해 바위·시작·도착 칸을 하나씩 옮겨 보며 최단 수를 목표에 맞추는 방식으로 만들고, 풀 수 있는 판만 써요. 퍼즐은 **한국 시간 자정**에 바뀌어요.
- **제출과 검증**: 화면에서 굴러가는 건 미리보기일 뿐이에요. 🍃에 도착하면 이동 기록(`UDLR` 문자열, 최대 80번)을 서버에 보내고, 서버가 시작 칸부터 그대로 다시 굴려서 도착하는지 확인해요. 도착한 뒤 이동이 섞여 있거나 못 도착한 기록, 날짜가 지난 판의 기록, 아직 안 열린 단계의 기록은 거절해요. 시간값은 쓰지 않아서 조작할 구석이 없어요.
- **순위**: 오늘 많이 깬 단계 순이고, 같으면 깬 단계들의 "최단 수 초과분 합"이 적은 순이에요. 성적이 같으면 같은 순위(1, 1, 3…)이고 먼저 달성한 사람이 위에 보여요. 퍼즐 화면에서 상위 20명과 내 순위를 볼 수 있어요.
- **별과 단계 보상**: ★★★ = 최단 수, ★★ = 최단+1~2수, ★ = 그 밖에 클리어. 단계마다 장비 조각 ★ 2개 · ★★ 3개 · ★★★ 4개를 받고, 더 높은 별을 따면 그 단계의 차액만 더 받아요.
- **단계 달성 보너스(하루 한 번씩)**: 3단계 🎟️1 · 5단계 🔩10·💎1 · 8단계 🎟️1·💎1 · 10단계 🎟️1·🔩20·💎2 (🎟️ 탐색권, 🔩 장비 조각). 10단계를 모두 최단으로 깨면 하루 합계 🎟️3 · 🔩70 · 💎4예요.
- **순위 보상(다음 날 받기)**: 어제 한 단계라도 깬 사람은 어제 순위로 1위 💎5 · 2위 💎3 · 3위 💎2 · 4~10위 💎1을 받아요. 퍼즐 화면에서 직접 받으며(어제 것만 받을 수 있어요), 같은 성적이면 모두 같은 순위예요.
- **저장**: 기록은 `puzzle_records`(하루 유저당 한 건, 45일 뒤 자동 삭제), 받은 보상 기록은 게임 상태의 `puzzle`에 보상과 한 번에 저장돼서 중복 지급이 없어요. 하루 한 판이던 시절의 옛 기록은 순위에서 빠져요.

### 콩 달리기
- **게임**: 콩벌레는 화면 왼쪽에 고정이고 땅이 흘러와요. 점프(스페이스·↑·W·화면 탭·화면 아래의 큰 점프 버튼)로 곰팡이를 넘고, 닿으면 끝이에요. 쓰러지지 않고 6분을 버티면 완주로 끝나요. 점프는 땅에서만 할 수 있고, 착지 직전에 누른 점프는 잠깐 기억해 뒀다가 착지하면 바로 뛰어요. 다른 탭으로 가면 자동으로 일시정지해요.
- **콩벌레 선택과 능력**: 가지고 있는 종 중 한 마리를 골라 달려요(고른 종의 그림이 달리고, 마지막에 고른 종을 기억해요). 희귀도마다 능력이 달라요: 일반 = 없음 · 희귀 = 🛡️ 껍질 1겹 · 에픽 = 껍질 1겹 + 🦘 점프력 +6% · 전설 = 껍질 2겹 + 점프력 +6% · 신화 = 껍질 2겹 + 점프력 +6% + 🌀 더블 점프(공중에서 한 번 더, 착지하면 다시 사용). 껍질은 곰팡이에 부딪혀도 한 겹이 깨지고 버티게 해 주고(깨진 뒤 1.5초는 무적), 곰팡이 배치는 어떤 콩벌레든 똑같아요(같은 시드 = 같은 판). 서툰 사람(타이밍 오차 약 67ms) 기준 중앙값이 일반 약 300m, 희귀 약 480m, 에픽 약 590m, 전설 약 680m예요. 종은 시작할 때 서버가 확인하고(가지고 있어야 해요) 희귀도를 판에 적어 두며, 끝날 때 그 희귀도로 서버가 다시 돌려서 점수를 정해요. 순위에는 기록을 세운 콩벌레의 그림과 이름(희귀도 색)이 같이 보여요(좁은 화면에서는 그림만, 이름은 길게 눌러 툴팁으로).
- **난이도**: 속도가 7초마다 올라요(초당 약 3.6m → 약 13m). 곰팡이는 낮은 것과 높은 것이 있고, 너비를 "점프 타이밍 여유(틱)"에서 거꾸로 계산해서 처음에는 여유가 넉넉하다가 갈수록 줄어요(좁은 타이밍에 넓은 곰팡이). 모든 판은 풀 수 있게 만들어져 있어요. 판(곰팡이 배치)은 달릴 때마다 서버가 정하는 시드로 정해져서 매번 달라요.
- **서버 검증**: 게임은 초당 60번(고정 간격) 진행하는 결정적 시뮬레이션이고, 사람이 하는 일은 "몇 번째 틱에 점프했는가"뿐이에요. 달리기를 시작하면 서버가 시드·시작 시각·내보낸 종의 희귀도를 적어 두고, 끝나면 클라이언트가 점프한 틱 목록(최대 4000개)만 보내요. 서버가 같은 시뮬레이션을 처음부터 다시 돌려서 거리를 스스로 계산하니 점수를 직접 보낼 곳이 없어요. 기록이 실제로 흐른 시간(시작 후 지난 시간 + 3초 여유)보다 길면 빨리 감기라서 거절하고, 시작한 지 40분 넘은 판은 무효예요. 한 판은 한 번만 끝낼 수 있고, 새로 시작하면 이전 판은 버려져요.
- **순위**: 그날 가장 멀리 달린 거리(미터)가 기록이에요. 같은 거리는 같은 순위(1, 1, 3…)이고 먼저 달성한 사람이 위에 보여요. 한국 시간 자정에 새로 시작해요.
- **거리 보너스(하루 한 번씩)**: 오늘 최고 기록이 150m 🔩5 · 400m 🔩10 · 800m 🎟️1·🔩10 · 1,500m 🔩15·💎1 · 2,500m 🎟️1·💎1에 닿을 때마다 받아요(하루 합계 🎟️2 · 🔩40 · 💎2). 나눠서 닿아도 합계는 같아요.
- **한계**: 판이 결정적이라 시드를 알면 완벽하게 뛰는 프로그램을 만들 수는 있어요. 기록이 실제 시간만큼 걸려야 하고 보너스에 하루 상한이 있어서 피해를 줄였을 뿐 막을 수는 없어요.
- **저장**: 기록은 `runner_records`(하루 유저당 한 건, 45일 뒤 자동 삭제), 달리는 판과 받은 보너스 기록은 게임 상태의 `runner`에 보상과 한 번에 저장돼요.

### 서바이벌
- 하루 **3회** 입장(입장할 때 차감, 쓰러지거나 그만둬도 돌려주지 않아요). 식구 한 마리를 골라 들어가면 그 식구의 레벨·장비가 반영된 능력치를 **입장할 때 한 번 굴려 고정**해요. 런 도중 레벨이나 장비를 바꿔도 이번 런에는 영향이 없어요.
- 1스테이지 적은 45 / 9 / 4(HP / 공격 / 방어)이고 스테이지마다 **8%씩(복리)** 강해져요. **5스테이지마다 엘리트**가 나오고 보스 패턴을 써요(30스테이지부터 두 개가 겹쳐요). 100스테이지를 모두 깨면 완주예요.
- 스테이지를 깰 때마다 최대 HP의 **15%** 를 회복하고, HP는 다음 스테이지로 이어져요. 쓰러지면 그 구간에서 멈춰요.
- **엘리트 직접 전투 모드**: 입장할 때 "🎮 엘리트 직접 전투"를 고르면 일반 스테이지는 자동으로 깨고, 5스테이지마다 나오는 엘리트와는 매 턴 행동(공격·방어 태세·강력한 일격·회복)을 직접 골라 싸워요(스테이지 수백 번을 일일이 고르면 지루해서 엘리트만 직접 해요). 보상·회복·버프 선택·부활 규칙은 자동 진행과 같고, 회복은 엘리트와 엘리트 사이(한 구간)에 한 번만 써요. 시뮬레이션 기준 평균 도달 스테이지는 자동 진행과 거의 같아요(공격만 고르면 같고, 예고를 읽고 대응하면 약 +1%).
- **부활과 추가 입장(💎)**: 쓰러진 런은 💎30 / 60 / 120(한 번의 도전에 최대 3번)으로 부활해서 같은 스테이지부터 이어갈 수 있어요(최대 HP의 60%로 되살아나요). 부활하지 않고 마치거나 새로 입장하면 그 런은 끝나요. 오늘 입장 3회를 모두 쓰면 추가 입장을 💎30 / 60 / 90(하루 최대 3회)에 살 수 있어요.
- 엘리트를 쓰러뜨리면 서버가 버프 후보 **3개**를 보여주고 하나를 골라야 다음 구간(5스테이지)이 진행돼요. 같은 버프는 중첩돼요.

| 버프 | 효과 |
|---|---|
| 날카로운 이빨 | 공격력 +25% |
| 단단한 껍질 | 방어력 +35% |
| 튼튼한 체력 | 최대 HP +25% (늘어난 만큼 바로 회복) |
| 숲의 휴식 | HP를 최대의 50% 회복 |
| 빠른 회복 | 스테이지를 깰 때마다 회복량 +5%p |

- 보상은 스테이지를 깰 때마다 바로 받아요: 골드 `15 + 5×스테이지`, 그 식구의 전투 경험치 `6 + 2×스테이지`. 이전 최고 기록을 넘어 새로 지나간 5스테이지 단위마다 💎2, 10 / 20 / 30 / 40스테이지에 처음 도달하면 희귀 / 에픽 / 전설 / 신화 장비를 1개 받아요.
- 진행 중인 런은 서버에 저장돼요. 새로고침하거나 다른 기기로 들어와도 같은 선택지가 그대로 보여요.

### 부스트 상점
- 수익 부스트(자동 수익 ×2) · 번식 촉진(번식 진행 ×2) · 전투 경험치 부스트(야생 배틀·훈련·보스·서바이벌 경험치 ×2). 1시간짜리와 4시간짜리(10% 저렴)가 있고, 같은 부스트를 이어서 사면 시간이 더해져요(최대 24시간).
- 1시간 가격은 내 사육장이 한 시간에 버는 최대 수익(쾌적한 환경 기준)에 비례해요. 번식 촉진·경험치 부스트는 그 금액 그대로, 수익 부스트는 15% 싸요. 아무리 작아도 1시간에 1,000 G예요.
- 부스트는 시작·종료 시각으로 저장되고, 시간이 흐르는 계산은 처리하는 구간과 겹친 부분에만 배율을 적용해요(구매 이전 시간은 부풀려지지 않아요).

### 장비
- 뽑기 1회 💎40, 10연차 💎360(마지막에 희귀 이상 보장). 등급 확률 55 / 28 / 12 / 4 / 1%, **50회 연속** 전설 이상이 안 나오면 50번째는 확정.
- 종류: 무기(공격) · 방어구(방어) · 장신구(HP), 총 30종. 효과 = 등급별 기본값(2 / 3 / 5 / 7 / 10%) × (1 + 0.15 × (레벨 − 1) + 0.05 × 각성 횟수).
- 레벨업은 같은 장비를 **현재 레벨 수치만큼** 모아야 해요(수동). 최대 레벨(기본 5)에서 골드로 **각성**(성공 70%, 실패할 때마다 +5%p)하면 최대 레벨 +3, 효과 +5%.
- 슬롯은 기본 3칸, 4번째 💎300, 5번째 💎666.
- **세트 효과**: 30종은 테마별 10개 세트(희귀도마다 2세트)로 묶여요. 한 세트는 무기·방어구·장신구 하나씩이고, 같은 세트를 **2개** 장착하면 공격력·방어력·HP가 모두 일반 +1% / 희귀 +1.5% / 에픽 +2% / 전설 +3% / 신화 +4%, **3개**면 +3% / +4.5% / +6% / +9% / +12%예요(3개 효과가 2개 효과를 대신해요). 5칸이면 한 세트 3개 + 다른 세트 2개를 함께 쓸 수 있어요.
- **장비 조각**: 쓰지 않는 중복(복사본)을 분해하면 조각을 얻어요(복사본 1개당 일반 4 / 희귀 10 / 에픽 25 / 전설 60 / 신화 150). 레벨업에 모자란 중복은 조각과 골드로 메꿀 수 있어요(모자란 1개당 조각 6 / 15 / 38 / 90 / 225 + 골드 100 / 300 / 1,000 / 3,000 / 10,000). 이미 모은 중복을 먼저 쓰고, 분해로 얻는 양보다 1.5배가 들어서 같은 장비를 직접 모으는 쪽이 늘 이득이에요. 장착 중인 장비의 중복은 일괄 분해에서 빠져요.

### 성장과 보상
- 계정 레벨업마다 다이아 3개. 새 종을 처음 만나면 다이아(일반 1 ~ 신화 15).
- 닉네임 변경 💎200, 종 별명은 무료.
- 친구 선물: 하루 한 번 서로에게 💎2.

## API 개요

모든 주소는 `/api` 아래에 있어요. 로그인(`auth/google*`)과 종·업그레이드·퀘스트·업적 목록(`species`, `upgrades`, `quests`, `achievements`)은 로그인 없이 열려 있고, 나머지는 `Authorization: Bearer <JWT>`가 필요해요. 관리자 전용은 `admin/...`이고 관리자 계정만 접근할 수 있어요.

| 영역 | 경로 |
|---|---|
| 인증 | `GET auth/google` · `GET auth/google/callback` · `GET auth/me` · `POST auth/profile-message` |
| 콘텐츠 | `GET species` · `upgrades` · `quests` · `achievements` · `equipment` · `boss` · `survival` |
| 게임 상태 | `GET game-state` · `POST game-state/{advance, care, observe, collect, explore, sell, species-lock, upgrade, terrariums, terrariums/rename, move, claim, claim-achievement, set-nickname, species-nickname}` |
| 전투 | `POST game-state/{battle, train, pvp/defense, pvp/battle, boss/battle}` · `GET game-state/pvp/opponent` · 직접 전투 `GET game-state/{boss,battle}/duel` · `POST game-state/{boss,battle}/duel/{start, act, forfeit}` |
| 서바이벌 | `GET survival`(규칙 안내) · `GET game-state/survival`(진행 상태) · `POST game-state/survival/{start(mode: auto|direct), choose, retire, revive, buy-attempt, duel/act}` |
| 오늘의 퍼즐 | `GET game-state/puzzle[?stage=N]`(고른 단계의 판·단계별 기록·내 순위·어제 결과·보상표) · `POST game-state/puzzle/{submit, claim-rank}` |
| 콩 달리기 | `GET game-state/runner`(오늘의 기록·최고 기록·보너스표) · `POST game-state/runner/{start(`speciesId`), finish(점프한 틱 목록 `jumps`)}` |
| 보스 편의(💎) | `POST game-state/boss/{buy-attempt, skip-cooldown}` |
| 부스트 상점 | `GET game-state/boosts`(가격표) · `POST game-state/boosts/buy` |
| 장비 | `POST game-state/equipment/{pull, level-up, level-up-shards, dismantle, awaken, equip, expand-slot}` |
| 원정 | `GET game-state/expedition`(가격표·천장) · `POST game-state/expedition` |
| 꾸미기 | `GET decor`(장식 카탈로그) · `POST game-state/decor/{buy, place, public}` |
| 사육장 방문 | `GET visit/random` · `GET visit/:userId` · `POST visit/:userId/like`(`terrariumId`, `liked`) |
| 프로필 | `GET game-state/profile/:userId` |
| 랭킹 | `GET leaderboard/{level, income, pvp, boss, survival, puzzle, runner, likes}[?limit=20|50|100]`(없거나 다른 값이면 20명) |
| 친구 | `GET friends` · `GET friends/search` · `POST friends/{request, accept, decline, remove, gift}` |
| 친구 채팅 | `GET friend-chat/unread` · `GET/POST friend-chat/:friendId/messages` · `DELETE friend-chat/:friendId/messages/:messageId` · `POST friend-chat/reports` |

| 우편함 | `GET mail` · `GET mail/summary` · `POST mail/claim-all` · `POST mail/:id/{claim, read}` · `DELETE mail/:id` |
| 푸시 | `GET push/config` · `GET/POST push/preferences` · `POST push/{subscribe, unsubscribe}` |

요청 본문은 `class-validator`로 검증하고, 잘못된 값은 `400`과 한국어 오류 메시지로 돌려줘요.

## 개발 가이드

### 서버와 프론트에 같은 계산이 두 벌 있어요
미리보기(비용·스탯·진행도)를 화면에서 바로 보여주려고 일부 상수와 함수가 양쪽에 있어요. **값을 바꿀 때는 두 곳을 함께** 고쳐야 해요.

| 백엔드 | 프론트엔드 |
|---|---|
| `game-state/game-engine.ts` | `frontend/src/utils/gameCalc.ts` |
| `game-state/puzzle-engine.ts`(굴리기 규칙) | `frontend/src/utils/puzzle.ts` |
| `game-state/runner-engine.ts`(콩 달리기 시뮬레이션) | `frontend/src/utils/runner.ts` (**한 틱도 어긋나면 안 돼요**) |
| `decor/decor.data.ts`의 `getDecorBreedBonusPercent`·`normalizeDecorProps`(꾸미기 번식 보너스 계산, 장식 목록은 `GET /decor`) | `frontend/src/utils/decor.ts` |

예: 탐색 비용(`EXPLORE_COST_*`), 장비 효과, 전투 스탯, 보스 난이도 진행도 필드, 업적 진행도 계산 등. 보스 층의 능력치·보상과 서바이벌의 규칙·버프 목록은 서버가 `GET /boss`, `GET /survival`로 내려줘서 프론트에 계산식이 없어요.

### 데이터의 기준
- 종·업그레이드·퀘스트·업적은 **시드 파일이 기준**이에요. 서버가 시작될 때마다 DB에 덮어써요(upsert). 종의 분양가와 분당 수익은 `species.seed-data.ts`의 `RARITIES` 한 곳에서 정해요. 종의 계열(불꽃·숲·서리)은 `species.family.ts`의 매핑이 기준이고 시드에 같이 쓰여요.
- 장식 카탈로그(`decor/decor.data.ts`)와 장비 카탈로그(`equipment/equipment.data.ts`)와 보스 층 정보(`getBossFloor`), 서바이벌 적 공식(`getSurvivalEnemy`)은 DB에 저장하지 않고 **코드가 기준**이에요.
- 새 업적 통계를 추가하려면 `AchievementStatKey`(백엔드 스키마), `game-engine.ts`의 `getAchievementProgress`, 프론트 `types.ts`·`gameCalc.ts`, 업적 아이콘(`AchievementsView.tsx`)을 함께 고쳐요.

### 업데이트 내역
새 기능·밸런스·수정을 반영할 때 `frontend/src/data/CHANGELOG.md`에 **날짜 → 카테고리(✨ 신규 기능 / ⚖️ 밸런스 / 🐛 수정 / 🛠️ 기타) → 항목** 순서로 적어요. 같은 파일을 게임 안 사이드바 '업데이트 내역' 화면이 그대로 읽어서(형식은 `utils/changelog.ts` 참고) 프론트를 다시 빌드하면 반영돼요. 🛠️ 기타와 커밋 해시는 게임 화면에서 숨겨요. 새 날짜가 생기면 아직 못 본 유저의 사이드바에 NEW가 떠요.

### Mongoose 주의점
- `@Prop({ type: Types.ObjectId })`로 선언한 필드는 스키마상 `Mixed`예요. 쿼리할 때 문자열 id를 그대로 쓰면 매칭되지 않으니 **항상 `new Types.ObjectId(id)`로 변환**해요.
- `string | null` 같은 유니온 타입은 `@Prop({ type: String })`처럼 타입을 명시해야 해요(안 하면 서버가 시작 중에 죽어요).
- `.lean()`은 스키마 기본값을 채우지 않아요. 새 필드를 추가하면 예전 문서는 값이 없을 수 있으니 `?? 기본값`으로 읽어요.
- 배열은 원소를 직접 대입하지 말고 배열 전체를 다시 대입해야 변경이 저장돼요.

### 배포 전 점검 (권장)
`npm run build` 후 다른 포트에서 먼저 띄워서(`PORT=3099 node dist/main.js`) 정상 시작하는지 확인하고 나서 운영 프로세스를 재시작하면 잘못된 배포로 서비스가 죽는 것을 막을 수 있어요.
